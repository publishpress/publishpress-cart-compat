# Feature catalog

Sellable capabilities for PublishPress Cart Compatibility. This companion does
not replace PublishPress Cart and is not a live StudioCart integration.

**Features** describe what the plugin can do for store owners. **Modules** (in
`.tests.config.yaml` and test-case frontmatter) group tests by code area — they
are not the same as features.

| ID | Name |
|----|------|
| [ppcart-compatibility-mode](ppcart-compatibility-mode.md) | StudioCart Compatibility Mode |
| [data-migration](data-migration.md) | StudioCart Data migration |
