# Compatibility Mode accepts a previous toggle row without migrating it

## Scenario

Existing sites can retain the prior Compatibility Mode option after the
canonical key becomes `_ppcart_compatibility_mode`. Compatibility Mode reads
that value in place; normal boot and feature checks never migrate it.

## Steps

1. Save the previous Compatibility Mode option as `1` and leave the canonical option absent.
2. Check support through canonical `ppcart-compatibility-mode` and the legacy feature ID.
3. Confirm the canonical option was not created and the prior row remains.
4. Save canonical `0` and confirm it takes precedence without altering the prior row.

## Expected result

Both feature IDs work only through the Compat feature gate. Canonical storage
wins when present. Historical option rows remain unchanged until an explicit
merchant migration exists.
