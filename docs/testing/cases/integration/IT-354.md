# IT-354 — Leftover recognition Compat bridges

## Goal

While Compatibility Mode is on, publishpress-cart-compat read-throughs leftover
`_my_account`, leftover FSE template slugs, and product-duplicate meta
rewrites without Cart silent migrate.

## Steps

1. Seed `_my_account` only and assert canonical read-through leaves the leftover
   row in storage (no Cart silent migrate).
2. With Compat on, assert `get_option('_ppcart_myaccount_page_id')` returns the
   leftover row and `_my_account` remains in storage.
3. With Compat on, assert leftover FSE slug list includes `single-sc_product`.
4. With Compat on, assert `ppcartcomp_product_duplicate_meta_key()` rewrites
   `_sc_pay_options` to `_ppcart_pay_options`.

## Expected

Leftover recognition works only in Compat while on. Cart first-party stays
canonical-only (UT-298).
