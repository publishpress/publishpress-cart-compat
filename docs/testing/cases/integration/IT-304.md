# Order item meta round-trips after custom table migration

## Scenario

Order item metadata written against leftover type `ncs_order_item` must remain readable after Data migration through canonical type `ppcart_order_item` and `$wpdb->ppcart_order_itemmeta`.

## Steps

1. Create leftover items + meta tables, insert an item, `add_metadata( 'ncs_order_item', ... )`.
2. Run `ppcart_migrate_custom_tables()` and re-register the live `$wpdb` meta table.
3. `get_metadata( 'ppcart_order_item', ... )` and write a new key with `update_metadata`.

## Expected result

The pre-migration meta value is returned from the canonical type, and a new write is stored on `{prefix}ppcart_order_itemmeta` using column `ppcart_order_item_id`.

## Edge cases

- `$wpdb->ncs_order_itemmeta` is unset after migration.
