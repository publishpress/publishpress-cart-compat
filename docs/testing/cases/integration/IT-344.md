# Leftover webhook and invoice URLs work only when Compatibility Mode is on

## Scenario

Bookmarked leftover `?sc-invoice=` links 302 to `ppcart-invoice` only while
Compatibility Mode is on. Leftover `/sc-webhook/` rewrite and POST `sc-api`
copy onto `ppcart-api` only while on. Mode off leaves leftover vars and
rewrite unregistered. First-party `api_query_vars` registers canonical names
only.

## Steps

1. Confirm `PPCart_Public::api_query_vars()` registers `ppcart-api` /
   `ppcart-invoice` and not leftover names.
2. With Compatibility Mode off, confirm leftover vars and rewrite are absent.
3. Enable Compatibility Mode and confirm leftover registration, leftover
   rewrite, invoice 302, and POST copy without a 302.

## Expected result

Leftover `sc-invoice` 302s to `ppcart-invoice` only while Compatibility Mode
is on. Leftover webhook rewrite and POST copy land on `ppcart-api` only while
on. Extra GET keys such as `token` remain.

## Edge cases

- Canonical `ppcart-api` / `ppcart-invoice` alone do not produce another redirect.
- POST leftover webhooks must not 302.
