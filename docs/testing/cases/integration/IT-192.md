# PPCart_Price_Format registers NCS_Cart_Price_Format and NCS_Price_Format aliases when Compatibility Mode is on

## Scenario

After the #629 helper rename, `PPCart_Price_Format` is the canonical price-format migration class. Third-party plugins that still reference `NCS_Cart_Price_Format` or bare `NCS_Price_Format` must receive working aliases when Compatibility Mode is enabled.

## Steps

1. Load `includes/class-ppcart-price-format.php` when the class is not already bootstrapped.
2. Enable `_ppcart_studiocart_compatibility_mode`.
3. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
4. Assert `class_exists( 'PPCart_Price_Format', false )`, `class_exists( 'NCS_Cart_Price_Format', false )`, and `class_exists( 'NCS_Price_Format', false )`.
5. Construct `new NCS_Cart_Price_Format()` and `new NCS_Price_Format()` and assert each is an instance of `PPCart_Price_Format`.

## Expected result

All three class names resolve to the same canonical price-format class when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (`test_IT_192_PPCart_Price_Format_legacy_aliases_unregistered_when_mode_is_off`), legacy names must not be registered even after the class file is required.
