# Hook bridges accept cron hooks fired with no arguments

## Scenario

WP-Cron runs scheduled events with `do_action_ref_array($hook, [])`, which passes no arguments. With Compatibility Mode on, the hook bridge's filter callbacks required a first argument, so a scheduled event stopped with an `ArgumentCountError`.

## Steps

1. Turn on Compatibility Mode.
2. Add a listener to a legacy hook.
3. Fire the canonical hook and the legacy hook with `do_action_ref_array()` and an empty argument list.

## Expected result

No error occurs, and the legacy listener runs.

## Edge cases

- None.
