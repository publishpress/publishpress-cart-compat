# Bootstrap canonical constants are defined without legacy aliases

## Scenario

Plugin bootstrap defines canonical `PPCART_*` runtime constants. With Compatibility Mode off (the default), mapped `NCS_CART_*` / `SC_*` names must not exist.

## Steps

1. Assert Compatibility Mode is off.
2. Assert bootstrap canonicals are defined: `PPCART_FREE_LOADED`, `PPCART_VERSION`, `PPCART_BASE_DIR`, `PPCART_BASE_URL`, `PPCART_BASE_FILE`, `PPCART_STYLESHEET_PATH`, `PPCART_LIB_VENDOR_PATH`, `PPCART_VENDOR_ASSETS_URL`, `PPCART_STRIPE_CONNECT_SERVER_URL`, plus the file-level minimum version constants.
3. For every mapped legacy name, assert the constant is undefined.

## Expected result

First-party bootstrap is `PPCART_*` only. Legacy constant names stay Compatibility Mode surface area.
