# Leftover $studiocart aliases $ppcart_public only while Compatibility Mode is on

## Scenario

Slice 31 stores the public coordinator on `$ppcart_public` (`PPCart_Public`).
Compatibility Mode off must not create leftover `$studiocart`. Compatibility
Mode on aliases leftover `$studiocart` onto `$ppcart_public` by reference.

## Steps

1. With Compatibility Mode off, assert `$studiocart` is absent and
   `$ppcart_public` is an instance of `PPCart_Public`.
2. Enable Compatibility Mode and call `maybe_register_globals()`.
3. Assert `$studiocart` is the same instance as `$ppcart_public`.
4. Write through either name and assert the other stays in sync.

## Expected result

- Bootstrap creates `$ppcart_public` as `PPCart_Public`.
- Leftover `$studiocart` exists only while Compatibility Mode is on, as a
  reference to `$ppcart_public`.

## Edge cases

- IT-263 already asserts mapped leftover names are absent while Compatibility
  Mode is off, including `$studiocart` after this map row.
- Writes through `$studiocart` must not remain after Compatibility Mode is
  turned off in a later request; this process keeps the alias until teardown
  unsets the leftover key.
