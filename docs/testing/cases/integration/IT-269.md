# Opt-in CPT slug migrator renames leftover product posts

## Scenario

Activate/upgrade only seed leftover detection. A merchant-started step 1 chunk
renames stored `sc_product` rows to `ppcart_product` and writes a restore map.
Restore undoes completed chunks without treating the merchant as having
acknowledged the notice. Seed stays leftover when a leftover role still exists
even if the store has no products.

## Steps

1. Insert a leftover `sc_product` post.
2. Call `ppcart_cpt_slug_migration_maybe_seed_state()` and confirm the post type
   is unchanged.
3. As an administrator, run one step 1 chunk.
4. Reload the post.

## Expected result

Seed leaves the leftover slug in place. The chunk renames the post to
`ppcart_product`.

## Edge cases

- Chunk size is 500; a single leftover row finishes in one request.
- Restore puts the leftover slug back and leaves `ack` unset.
- Seed with leftover `sc_cart_manager` does not mark the site canonical.
