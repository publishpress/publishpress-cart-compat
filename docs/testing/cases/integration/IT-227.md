# Compatibility Mode registers stripe sync, logging, secrets, and files class aliases

## Scenario

Issue #629 set 7 renames stripe sync, logging, secrets, and files classes to `PPCart_*`. Third-party plugins that still reference `NCS_Cart_*` names must receive working aliases when Compatibility Mode is enabled.

## Steps

1. Assert `PPCart_Files` is canonical while Compatibility Mode is off.
2. Enable `_ppcart_compatibility_mode`.
3. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
4. Assert each canonical class has a matching `NCS_Cart_*` alias.
5. Construct representative legacy instances and assert they are instances of the canonical classes.

## Expected result

All mapped stripe sync, logging, secrets, and files class names resolve to the same canonical implementations when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (IT-220 through IT-226), legacy names must not be registered even though the canonical `PPCart_*` classes are loaded.
