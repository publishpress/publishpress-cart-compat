# Leftover transient rows copy onto canonical keys; leftover names work only with Compatibility Mode on

## Scenario

Leftover `_transient_sc_*` / `_transient_timeout_sc_*` rows copy onto canonical
keys. Compatibility Mode maps leftover `get_transient('sc_*')` onto canonical
rows. Mode off does not bridge leftover names.

## Steps

1. Seed leftover `_transient_sc_*` plus timeout, run the option copier, assert
   canonical exists and leftover is gone.
2. Enable Compatibility Mode and assert leftover `get_transient('sc_*')`
   returns the canonical value.

## Expected result

Boot copy moves leftover transient option rows; canonical wins. Leftover PHP
names work only while Compatibility Mode is on.

## Edge cases

- Object-cache leftover transients are not copied (documented gap).
- First-party Cart writes of `ppcart_*` transients stay in PublishPress Cart
  (same case id, first-party half).
