# Enabling Compatibility Mode loads legacy function wrappers

## Scenario

When the merchant enables StudioCart Compatibility Mode, the function shim file is required once. That file exposes the StudioCart-era bootstrap names as wrappers around the canonical `ppcart_*` functions.

## Steps

1. Enable `_ppcart_compatibility_mode`.
2. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_functions()`.
3. Assert `legacy_functions_registered()` is true.
4. Assert `activate_ncs_cart`, `deactivate_ncs_cart`, `upgrade_ncs_cart`, and `run_ncs_cart` exist alongside the canonical names.

## Expected result

The four leftover bootstrap names are available only while Compatibility Mode is on.
