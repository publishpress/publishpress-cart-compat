# Leftover sc-cart CPT/taxonomy option filter listeners run only when Compatibility Mode is on

## Scenario

Canonical `apply_filters('ppcart_cpt_options')` and
`apply_filters('ppcart_taxonomy_options')` reach leftover
`sc-cart-cpt-options` / `sc-cart-taxonomy-options` listeners only while
Compatibility Mode is on.

## Steps

1. With Compatibility Mode off, add leftover listeners and fire the canonical filters.
2. Enable Compatibility Mode, register hook bridges, and fire the canonical filters again.
3. Fire leftover filter names and assert canonical listeners run.

## Expected result

Leftover listeners do not mutate values when Compatibility Mode is off. They
mutate canonical filter values when it is on. Reverse leftover `apply_filters`
reaches canonical listeners when on.

## Edge cases

- CPT filter passes `$opts, $cpt_name`; taxonomy filter passes `$opts` only.
- Canonical listeners always run.
