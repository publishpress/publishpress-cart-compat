# PPCart_Order_Items registers NCS_Cart_Order_Items alias when Compatibility Mode is on

## Scenario

After the #629 model rename, `PPCart_Order_Items` is the canonical order items service class. Legacy callers using `NCS_Cart_Order_Items` must keep working when Compatibility Mode is enabled.

## Steps

1. Require the order items classes if they are not already loaded.
2. Enable `_ppcart_studiocart_compatibility_mode`.
3. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
4. Assert `class_exists( 'PPCart_Order_Items', false )` and `class_exists( 'NCS_Cart_Order_Items', false )`.
5. Construct `new NCS_Cart_Order_Items()` and assert it is an instance of `PPCart_Order_Items`.

## Expected result

Both class names resolve to the same canonical order items service when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (`test_IT_169_PPCart_Order_Items_legacy_aliases_unregistered_when_mode_is_off`), `NCS_Cart_Order_Items` must not be registered.
