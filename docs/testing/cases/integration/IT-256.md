# Legacy function wrappers stay unloaded while Compatibility Mode is off

## Scenario

On a default install, canonical bootstrap functions (`ppcart_activate`, `ppcart_deactivate`, `ppcart_upgrade`, `ppcart_run`) are defined and registered with WordPress. Compatibility Mode is off, so the StudioCart-era names stay undefined.

## Steps

1. Boot the integration suite with Compatibility Mode unset.
2. Assert `PPCart_Studiocart_Compatibility_Mode::legacy_functions_registered()` is false.
3. Assert each canonical bootstrap function exists.
4. Assert `activate_ncs_cart`, `deactivate_ncs_cart`, `upgrade_ncs_cart`, and `run_ncs_cart` do not exist.
5. Assert activation, deactivation, and `upgrader_process_complete` callbacks point at the canonical names.

## Expected result

First-party bootstrap is `ppcart_*` only. Legacy bootstrap function names stay Compatibility Mode surface area.
