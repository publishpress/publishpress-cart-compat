# Leftover GET sc-revoke and sc-revoked copy only while Compatibility Mode is on

## Scenario

Cart reads canonical GET `ppcart-revoke` / `ppcart-revoked`. Compatibility Mode
copies leftover `sc-revoke` / `sc-revoked` onto those keys while the toggle is
on.

## Steps

1. With Compatibility Mode off, assert leftover GET is not copied.
2. Enable Compatibility Mode and copy leftover GET `sc-revoke` / `sc-revoked`.
3. Assert the canonical keys receive the leftover values while the leftover
   keys remain.

## Expected result

Leftover GET `sc-revoke` / `sc-revoked` are absent from canonical keys while
Compatibility Mode is off and copied while on.

## Edge cases

- Canonical GET wins when both leftover and canonical keys are present.
- Cart first-party never reads leftover `sc-revoke` / `sc-revoked` (UT-306).
