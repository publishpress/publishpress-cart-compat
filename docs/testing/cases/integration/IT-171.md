# Gutenberg assets registers NCS_Cart_Gutenberg_Assets alias when Compatibility Mode is on

## Scenario

Third-party code that still references `NCS_Cart_Gutenberg_Assets` must resolve to the canonical `PPCart_Gutenberg_Assets` when Compatibility Mode is enabled.

## Steps

1. In an isolated process with Compatibility Mode off, assert `PPCart_Gutenberg_Assets` exists and `NCS_Cart_Gutenberg_Assets` does not.
2. Enable `_ppcart_compatibility_mode` and call `maybe_register_aliases()`.
3. Assert both class names exist and `new NCS_Cart_Gutenberg_Assets(...)` is a `PPCart_Gutenberg_Assets`.

## Expected result

The legacy Gutenberg assets name aliases the canonical class only when Compatibility Mode is on.
