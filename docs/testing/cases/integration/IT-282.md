# Canonical shortcodes exist; leftover tags register only in Compatibility Mode

## Scenario

Core registers `ppcart_*` shortcodes. Leftover StudioCart tags appear only
while Compatibility Mode is on, and they share the canonical callback.

## Steps

1. With the mode off, assert canonical tags exist and leftover tags do not.
2. Enable Compatibility Mode and register leftover tags.
3. Confirm account vs order detail tags stay distinct.

## Expected result

Mode off: only `ppcart_*` tags exist. Mode on: leftover tags exist and match
the canonical callback. `ppcart_account_order_detail` and `ppcart_order_detail`
remain two tags.

## Edge cases

- Unregister leftover tags after the on-mode case so later tests stay clean.
