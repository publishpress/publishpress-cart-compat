# Leftover Compatibility Mode option migrates on a live WordPress site

## Scenario

A site that stored Compatibility Mode as `_sc_studiocart_compatibility_mode` must keep the feature on after the merchant toggle moved to `_ppcart_studiocart_compatibility_mode`. `is_user_enabled()` copies the leftover `wp_options` row onto the canonical key and deletes the leftover row.

## Steps

1. Delete `_ppcart_studiocart_compatibility_mode` if present.
2. Save `_sc_studiocart_compatibility_mode` as `1`.
3. Call `PPCart_Studiocart_Compatibility_Mode::is_user_enabled()`.
4. Read both option keys from the database.

## Expected result

`is_user_enabled()` returns `true`. `get_option( '_ppcart_studiocart_compatibility_mode' )` is `1`. The leftover option is gone.

## Edge cases

- Settings still bind the checkbox to the canonical option id (IT-165).
