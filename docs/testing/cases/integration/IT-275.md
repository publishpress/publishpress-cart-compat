# Oldest Compatibility Mode option remains in place on a live WordPress site

## Scenario

A site that stored Compatibility Mode as `_sc_studiocart_compatibility_mode` must keep the feature on. `is_user_enabled()` reads the historical `wp_options` row without copying or deleting it.

## Steps

1. Leave `_ppcart_compatibility_mode` absent.
2. Save `_sc_studiocart_compatibility_mode` as `1`.
3. Call `PPCart_Studiocart_Compatibility_Mode::is_user_enabled()`.
4. Read both option keys from the database.

## Expected result

`is_user_enabled()` returns `true`. `get_option( '_ppcart_compatibility_mode' )` remains absent and the historical option remains `1`.

## Edge cases

- Settings still bind the checkbox to the canonical option id (IT-165).
