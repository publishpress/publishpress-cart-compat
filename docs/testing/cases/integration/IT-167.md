# PPCart_Subscription registers NCS_Cart_Subscription and ScrtSubscription aliases when Compatibility Mode is on

## Scenario

After the #629 model rename, `PPCart_Subscription` is the canonical subscription class. Legacy callers using `NCS_Cart_Subscription` or `ScrtSubscription` must keep working when Compatibility Mode is enabled.

## Steps

1. Enable `_ppcart_compatibility_mode`.
2. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
3. Assert `class_exists( 'PPCart_Subscription', false )`, `class_exists( 'NCS_Cart_Subscription', false )`, and `class_exists( 'ScrtSubscription', false )`.
4. Construct `new NCS_Cart_Subscription()` and `new ScrtSubscription()` and assert each is an instance of `PPCart_Subscription`.

## Expected result

All three class names resolve to the same canonical subscription model when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (`test_IT_167_PPCart_Subscription_legacy_aliases_unregistered_when_mode_is_off`), legacy subscription names must not be registered.
