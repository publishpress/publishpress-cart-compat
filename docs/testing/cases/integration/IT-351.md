# Leftover Gutenberg checkout block dual-registers only while Compatibility Mode is on

## Scenario

Cart registers only `publishpress-cart/checkout-form`. Compatibility Mode dual-registers leftover `sc-products-shortcode/product-shortcode` onto the same render callback so persisted leftover blocks still render while the toggle is on.

## Steps

1. With Compatibility Mode off, assert leftover is not registered.
2. Enable Compatibility Mode and call leftover Gutenberg registration.
3. Assert leftover is registered with the canonical render callback.
4. Render leftover block markup and assert the checkout form appears.
5. Enqueue leftover editor assets and assert the Compat script/style handles.

## Expected result

Leftover checkout block is absent while Compatibility Mode is off and registered/rendered while on. Editor CSS and JS load only while on.

## Edge cases

- Canonical `publishpress-cart/checkout-form` stays registered in both modes.
- Persisted leftover block comments are not rewritten.
