# IT-355 — Metadata bridges ppcartcomp callbacks

## Goal

While Compatibility Mode is on, publishpress-cart-compat metadata API bridges
register `ppcartcomp_*` callbacks that read leftover `_sc_*` meta through
canonical rows. When off, bridges are absent.

## Steps

1. With Compat off, assert `ppcartcomp_get_post_metadata` is not registered.
2. Enable Compatibility Mode and call `maybe_register_metadata_bridges()`.
3. Assert `ppcartcomp_*` callbacks are registered on metadata filters.
4. Seed `_sc_amount` only and assert `get_post_meta(…, '_sc_amount')` returns
   the canonical value via the bridge.

## Expected

Metadata bridges work only in Compat while on, using `ppcartcomp_*` names.
Cart live helpers stay `ppcart_*` (UT-299).
