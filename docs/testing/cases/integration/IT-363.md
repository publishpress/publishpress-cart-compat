# Leftover Elementor widgets and Divi slug dual-register only while Compatibility Mode is on

## Scenario

Pro registers canonical Elementor widgets (`ppcart-countdown`, `ppcart-orderform`,
`ppcart-bump-*`) and Divi slug `ppcart_order_form` only. Compatibility Mode
dual-registers leftover widget names and leftover Divi slug
`stof_studiocart_order_form` so stored builder JSON/shortcodes still render
while the toggle is on. Stored `_elementor_data` is not rewritten on boot.

## Steps

1. With Compatibility Mode off, call leftover Elementor/Divi registration.
2. Assert leftover registration trackers stay empty.
3. Enable Compatibility Mode and call leftover registration again.
4. If Elementor + Pro widgets are loaded, assert leftover widget names are tracked.
5. If Divi + Pro module class are loaded, assert leftover slug is tracked.
6. If those builders are absent, leftover registration is a no-op.

## Expected result

Leftover Elementor/Divi names are absent while Compatibility Mode is off and
registered while on when the builders exist. No Pro dual-register. No silent
data migration.

## Edge cases

- Canonical widget names stay registered in both modes.
- Merchant Data migration walker for `_elementor_data` is a follow-up, not this case.
