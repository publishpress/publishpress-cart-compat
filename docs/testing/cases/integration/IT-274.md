# Migration control plane forbids, pauses, locks, acks, and redirects

## Scenario

Step 1 is administrator-only. A stop request while a chunk is running pauses
without treating the step as complete. A held lock returns busy. Acknowledging
the leftover notice with `later` hides it. The leftover notice is also hidden
on the retired Data migration submenu and on Cart → StudioCart
(`page=ppcart-studiocart`). It still shows on Cart Settings. Old
`page=ppcart-migration` bookmarks redirect to Cart → StudioCart. After step
1, leftover admin query strings for post types and taxonomies redirect to
canonical slugs. Delete backup drops the reverse-map table.

## Steps

1. Run a step 1 chunk as a subscriber.
2. Save `step1=running` and `stop_requested` and run a chunk.
3. Set the step 1 lock transient and run a chunk.
4. Insert a leftover order and toggle `ack=later`.
5. Insert a leftover order and request `page=ppcart-migration`, then
   `page=ppcart-studiocart`, then `page=ppcart-settings`.
6. Request `page=ppcart-migration` and capture the redirect.
7. Confirm Data migration deep-links Cart → StudioCart (no Settings section).
8. Mark step 1 complete, set `is_admin`, and request leftover `post_type` /
   `taxonomy` query args.
9. Create the reverse-map table and delete the backup.

## Expected result

Non-admins get `forbidden`. Stop returns `paused` and clears the stop flag.
The lock returns `busy`. The notice is hidden after ack, on the retired
submenu, and on Cart → StudioCart. It remains on Cart Settings.
`page=ppcart-migration` redirects to `page=ppcart-studiocart`.
Leftover
`post_type=sc_product` redirects to `ppcart_product` and leftover
`taxonomy=sc_product_cat` redirects to `ppcart_product_cat`. Delete backup
drops the reverse-map table.

## Edge cases

- Redirect tests stub `is_admin()`, filter `wp_doing_rest` off (CheckoutBlock
  preview tests define `REST_REQUEST` for the rest of the process), and catch
  `wp_redirect` so `exit` after `wp_safe_redirect` is never reached.
- Pause is checked before leftover work, so leftover rows are not required.
