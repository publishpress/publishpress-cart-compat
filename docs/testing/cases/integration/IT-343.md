# Leftover shortcode detectors run only when Compatibility Mode is on

## Scenario

Unmigrated leftover shortcode tags must load frontend assets, add the account
body class, and skip the default order summary only while Compatibility Mode
is on. Mode off ignores leftover openings.

## Steps

1. Insert a page with `[studiocart-form]` and check `frontend_assets_needed`
   with Compatibility Mode off, then on.
2. Run leftover account body-class and leftover order-summary skip helpers
   off then on.

## Expected result

Leftover form content does not need assets while off and does while on.
Leftover `studiocart_account` adds `account-page` only while on. Leftover
`sc_order_summary_items_view` skips the default summary only while on.

## Edge cases

- Canonical detectors stay in Cart (UT-271 / IT-283).
- Leftover email replace stays covered by IT-283.
