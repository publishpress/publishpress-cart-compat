# Leftover before_sc_order_refund listeners run only when Compatibility Mode is on

## Scenario

Canonical `do_action('ppcart_before_order_refund')` reaches leftover
`before_sc_order_refund` listeners only while Compatibility Mode is on.

## Steps

1. With Compatibility Mode off, add a leftover listener and fire the canonical hook.
2. Enable Compatibility Mode, register hook bridges, and fire the canonical hook again.

## Expected result

Leftover listeners do not run when Compatibility Mode is off. They run when
it is on.

## Edge cases

- Canonical listeners always run.
- Reverse leftover `do_action('before_sc_order_refund')` also reaches canonical listeners when on.
