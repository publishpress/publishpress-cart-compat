# Compatibility Mode defines legacy constant aliases from canonical values

## Scenario

When Compatibility Mode is enabled after bootstrap, outbound aliases expose mapped `NCS_CART_*` / `SC_*` names with the same values as the canonical `PPCART_*` constants. Names whose canonical counterpart was never defined stay undefined.

This case lives in `ZPrefixCompatibilityModeOnTest` because PHP constants cannot be undefined in-process after they are created.

## Steps

1. Enable Compatibility Mode and call `maybe_register_constants()`.
2. For every mapped pair, if the canonical constant is defined, assert the legacy alias is defined and equal.
3. If the canonical constant is not defined, assert the legacy name stays undefined.

## Expected result

Every renamed runtime constant that exists canonically is aliased for third-party code, and only while Compatibility Mode is on.
