# Data migration rewrites leftover shortcode tags in Elementor data

## Scenario

Elementor renders pages from `_elementor_data` post meta, not from
`post_content`. The Shortcode tags step must rewrite leftover tags there too,
keep the JSON valid, clear Elementor's element cache, and restore the exact
original value (publishpress/publishpress-cart#935).

## Steps

1. Save `_elementor_data` the way Elementor does (`wp_slash( wp_json_encode() )`)
   with a Shortcode widget and a Text Editor widget that hold leftover tags.
2. Save `_elementor_element_cache`.
3. Run the Shortcode tags step until done.
4. Run Restore.

## Expected result

The JSON decodes, both widgets hold canonical tags, the element cache is
deleted, and the Elementor remaining count is 0. Restore puts back the exact
original JSON string.

## Edge cases

- `post_content` and email targets are IT-284 / IT-349.
