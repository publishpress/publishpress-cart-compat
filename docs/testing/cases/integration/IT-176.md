# Account detail controller registers NCS_Cart_Account_Detail_Controller alias when Compatibility Mode is on

## Scenario

Third-party code that still references `NCS_Cart_Account_Detail_Controller` must resolve to the canonical `PPCart_Account_Detail_Controller` when Compatibility Mode is enabled.

## Steps

1. In an isolated process with Compatibility Mode off, assert `PPCart_Account_Detail_Controller` exists and `NCS_Cart_Account_Detail_Controller` does not.
2. Enable `_ppcart_compatibility_mode` and call `maybe_register_aliases()`.
3. Assert both class names exist and `new NCS_Cart_Account_Detail_Controller(...)` is a `PPCart_Account_Detail_Controller`.

## Expected result

The legacy account detail controller name aliases the canonical class only when Compatibility Mode is on.
