# Compatibility Mode registers admin controller and dashboard class aliases

## Scenario

Issue #629 set 6 renames admin controller and dashboard classes to `PPCart_*`. Third-party plugins that still reference `NCS_Cart_Admin_*` and `NCS_Cart_Dashboard_*` names must receive working aliases when Compatibility Mode is enabled.

## Steps

1. Enable `_ppcart_compatibility_mode`.
2. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
3. Assert each canonical admin controller and dashboard class has a matching `NCS_Cart_*` alias.
4. Construct representative legacy instances and assert they are instances of the canonical classes.

## Expected result

All mapped admin controller and dashboard class names resolve to the same canonical implementations when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (IT-208 through IT-218), legacy names must not be registered even though the canonical `PPCart_*` classes are loaded.
