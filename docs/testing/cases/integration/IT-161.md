# Legacy compat helpers load from StudioCart Compatibility Mode

## Scenario

The old `includes/compat/legacy.php` loader is gone. After WordPress boots with PublishPress Cart active, the Compatibility Mode module must be the home of the shipped helper functions, class, and bootstrap hooks.

## Steps

1. Boot the integration suite (plugin active).
2. Check that `includes/compat/legacy.php` is not on disk.
3. Check that `PPCartComp_Studiocart_Compatibility_Mode` and the alias helpers exist (including global-map helpers).
4. Check that `ppcart_before_load` and `ppcart_supports_feature` are hooked to the module.

## Expected result

The module class and helpers are loaded. The deleted loader file is absent. Bootstrap hooks point at the new module.

## Edge cases

- Helper function names stay `ncs_cart_*` so existing tests and Pro aliases keep working.
