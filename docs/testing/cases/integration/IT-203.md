# PPCart_Order_Admin is canonical under Compatibility Mode prefix rename

## Scenario

Issue #629 set 5 renames admin screen classes to `PPCart_Order_Admin`. `NCS_Cart_Order_Admin` must exist only when StudioCart Compatibility Mode is enabled.

## Steps

1. Boot the integration suite with Compatibility Mode off.
2. Assert `PPCart_Order_Admin` is loaded as the canonical class.
3. Assert `NCS_Cart_Order_Admin` is not registered via `class_alias` while the feature is off.

## Expected result

`class_exists('PPCart_Order_Admin', false)` is true and `class_exists('NCS_Cart_Order_Admin', false)` is false with Compatibility Mode off.

## Edge cases

- IT-207 runs alias registration after IT-206; do not enable Compatibility Mode in IT-193 through IT-206.
