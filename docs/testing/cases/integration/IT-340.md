# Leftover invoice format values map only when Compatibility Mode is on

## Scenario

Sites that still store leftover `sc_pns` / `sc_pn` / `sc_ns` / `sc_n` in
`_ppcart_invoice_format` must reach first-party canonical `ppcart_*` codes
only while Compatibility Mode is on. Mode off leaves the leftover string
unmapped. The option row is not rewritten.

## Steps

1. Store leftover `sc_ns` in `_ppcart_invoice_format`.
2. Read via `ppcart_get_invoice_format()` with Compatibility Mode off and
   confirm the leftover string is returned.
3. Enable Compatibility Mode and read again.
4. Confirm the getter returns `ppcart_ns` and `get_option` still has `sc_ns`.

## Expected result

Leftover stored values map onto canonical codes only while Compatibility
Mode is on. Stored option rows are not rewritten.

## Edge cases

- Canonical `ppcart_*` values pass through unchanged.
- Query arg `ppcart-invoice` is slice 43, not this family.
