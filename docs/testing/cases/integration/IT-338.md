# Leftover sc-csv-export redirects only when Compatibility Mode is on

## Scenario

Bookmarked leftover `?sc-csv-export=` export URLs must 302 to
`ppcart-csv-export` only while Compatibility Mode is on. Mode off leaves the
leftover query var unregistered. First-party `api_query_vars` registers the
canonical name only.

## Steps

1. Confirm `PPCart_Public::api_query_vars()` registers `ppcart-csv-export` and
   not `sc-csv-export`.
2. With Compatibility Mode off, confirm leftover `sc-csv-export` is not
   registered.
3. Enable Compatibility Mode and confirm leftover registration plus a 302
   mapping that preserves unrelated GET keys.

## Expected result

Leftover `sc-csv-export` registers and redirects to `ppcart-csv-export` only
while Compatibility Mode is on. Extra keys such as `type` and `_wpnonce`
remain.

## Edge cases

- Canonical `ppcart-csv-export` alone does not produce another redirect.
- CSV is registered on `PPCart_Public::api_query_vars()`, not the page
  controller `query_vars()` list from slice 10.
