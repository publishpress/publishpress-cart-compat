# Leftover activate/upgrade/product hook listeners run only when Compatibility Mode is on

## Scenario

Canonical `do_action('ppcart_activate')` / `ppcart_upgrade` and
`apply_filters('ppcart_product')` / `ppcart_product_price` reach leftover
`ncs_activate` / `sc_activate` / `ncs_upgrade` / `sc_upgrade` / `sc_product` /
`sc_product_price` listeners only while Compatibility Mode is on. Mangled
`ppcart_ctivate` listeners never run.

## Steps

1. With Compatibility Mode off, add leftover listeners and fire the canonical hooks.
2. Enable Compatibility Mode, register hook bridges, and fire the canonical hooks again.
3. Fire leftover names and assert canonical listeners run.
4. Assert a mangled `ppcart_ctivate` listener does not run.

## Expected result

Leftover listeners do not run when Compatibility Mode is off. They run when it
is on. Reverse leftover fires reach canonical listeners when on. Mangled tags
are not Compat aliases.

## Edge cases

- Leftover filter `sc_product` is `add_filter`, not the leftover shortcode tag.
- Bootstrap function wrappers `activate_ncs_cart` are slice 1, not this family.
