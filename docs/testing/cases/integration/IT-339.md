# Leftover integration repeater keys copy only when Compatibility Mode is on

## Scenario

Stored cancel-subscription rows that still use leftover `sc_sub_*` inner keys
must reach first-party `ppcart_sub_*` keys only while Compatibility Mode is
on. Mode off leaves the leftover keys unread. Stored rows stay leftover.

## Steps

1. Save a product `_ppcart_integrations` row with leftover inner keys.
2. Read via `ppcart_get_post_meta(..., 'integrations')` with Compatibility
   Mode off and confirm canonical keys are absent.
3. Enable Compatibility Mode and read again.
4. Confirm canonical keys are filled, leftover keys remain, and
   `get_post_meta` still has leftover keys only.

## Expected result

Leftover inner keys copy onto canonical keys only while Compatibility Mode
is on. Stored rows are not rewritten.

## Edge cases

- Canonical wins when both leftover and canonical keys are present.
- Leftover `services` values remap in slice 49; leftover inner keys stay this family.
