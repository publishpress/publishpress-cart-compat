# Leftover integration trigger listeners run only when Compatibility Mode is on

## Scenario

After slice 34, first-party fires canonical `ppcart_order_complete` (and the
rest of the integration trigger family). Third parties that still
`add_action( 'sc_order_complete' )` must run only while Compatibility Mode
is on.

## Steps

1. Attach leftover listeners for `sc_order_complete` (and representative
   twins) with Compatibility Mode off and fire the canonical tags.
2. Enable Compatibility Mode, register hook bridges, and fire again.
3. Assert leftover listeners stay silent off and run on.

## Expected result

Leftover `sc_order_complete` / `sc_order_marked_complete` /
`sc_subscription_trialing` listeners run when canonical tags fire only while
Compatibility Mode is on. The rest of the family is locked by the mechanical
hook map (UT-256).

## Edge cases

- Canonical listeners on `PPCart_Public` are unaffected by the leftover
  bridge.
- Mechanical `sc_` → `ppcart_` mapping covers this family; no extra map rows.
