# Leftover POST and GET keys reach first-party only when Compatibility Mode is on

## Scenario

Compatibility Mode copies leftover StudioCart POST/GET keys onto canonical
keys. Mode off leaves leftover keys unread by first-party.

## Steps

1. Post leftover `sc-nonce` / GET leftover `sc_product_duplicated` with
   Compatibility Mode off and confirm canonical keys are absent.
2. Enable Compatibility Mode and copy again.
3. Confirm canonical keys are filled and leftover keys remain.

## Expected result

Leftover writers work only while Compatibility Mode is on.

## Edge cases

- Canonical wins when both leftover and canonical keys are present.
- `action` is not copied.
- First-party checkout emit stays in PublishPress Cart (same case id,
  first-party half).
