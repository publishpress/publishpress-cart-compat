# Leftover integration service ids copy only when Compatibility Mode is on

## Scenario

Stored `_ppcart_integrations` rows that still use leftover `services`
values must reach first-party canonical ids only while Compatibility Mode
is on. Mode off leaves leftover values unread. Stored rows stay leftover.

## Steps

1. Save a product `_ppcart_integrations` row with leftover `services` values.
2. Read via `ppcart_get_post_meta(..., 'integrations')` with Compatibility
   Mode off and confirm leftover ids remain.
3. Enable Compatibility Mode and read again.
4. Confirm canonical ids are filled and `get_post_meta` still has leftover
   `services` values.

## Expected result

Leftover `services` values remap onto canonical ids only while
Compatibility Mode is on. Stored rows are not rewritten.

## Edge cases

- Slice 36 leftover inner keys still copy on the same read path.
- Canonical `services` wins when the stored value is already canonical.
