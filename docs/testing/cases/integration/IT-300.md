# Activate and upgrade do not rename leftover custom tables

## Scenario

Leftover StudioCart tables must keep leftover names across plugin activation and upgrade. `setup_tax_table()`, order-item setup, and downloads setup CREATE/dbDelta the live names only. They must not `RENAME TABLE`.

## Steps

1. Drop canonical `ppcart_*` tables and create leftover `ncs_*` tables with a marker row.
2. Run `PPCart_Activator::setup_tax_table()`, `PPCart_Order_Items::setup_items_table()`, `PPCart_Files::setup_download_table()`, and `PPCart_Upgrade::setup_tax_table()`.
3. Inspect leftover vs canonical table existence and the marker row.

## Expected result

Leftover tables still exist, canonical tables were not created by renaming, and the marker row is unchanged.

## Edge cases

- Upgrade must behave the same as activate: no auto-rename.
