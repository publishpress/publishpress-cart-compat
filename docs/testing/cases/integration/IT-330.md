# Compat bridges leftover Pro AJAX username and lead actions

## Scenario

Slice 30 maps leftover `sc_check_username` / `sc_capture_lead` onto canonical `ppcart_*` actions in Compatibility Mode. Free does not register Pro handlers. Leftover WordPress AJAX hooks exist only while Compatibility Mode is on, with auth and nopriv.

## Steps

1. With Compatibility Mode off, assert `wp_ajax_sc_check_username`, `wp_ajax_nopriv_sc_check_username`, `wp_ajax_sc_capture_lead`, and `wp_ajax_nopriv_sc_capture_lead` are absent.
2. Enable Compatibility Mode and call `maybe_register_ajax()`.
3. Assert all four leftover hooks are registered.

## Expected result

Leftover Pro AJAX action bridges register only when Compatibility Mode is on, with auth + nopriv parity.

## Edge cases

- Canonical `wp_ajax_ppcart_check_username` / `ppcart_capture_lead` remain unregistered in Free (handlers live in Pro).
- Free JS already posts the canonical action names after slice 30.
