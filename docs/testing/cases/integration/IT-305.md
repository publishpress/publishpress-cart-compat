# Price format updates the live order items table

## Scenario

`PPCart_Price_Format::update_order_items_amount()` must query `ppcart_live_table( 'order_items' )`, not a hardcoded leftover or canonical name. On a leftover install it must rewrite amounts in `{prefix}ncs_order_items`.

## Steps

1. Drop canonical order-item tables and create leftover tables.
2. Insert an order item whose `total_amount` uses a non-US thousand/decimal format.
3. Set `_sc_thousand_separator` / `_sc_decimal_separator` and run price format.

## Expected result

The leftover row is updated to a normalized numeric string. A missing canonical table is not required for the update to succeed.

## Edge cases

- After Data migration, the same formatter must hit `{prefix}ppcart_order_items` instead.
