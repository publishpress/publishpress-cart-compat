# Leftover admin AJAX POST keys and sc_tax_settings bridge only while Compatibility Mode is on

## Scenario

Cart reads canonical `ppcart_ajax_nonce` / `ppcart_action` and
`ppcart_tax_settings`. Compatibility Mode copies leftover `ncs_ajax_nonce` /
`ncs_action` onto canonical POST keys and aliases `sc_tax_settings` to
`ppcart_tax_settings` in JS while the toggle is on.

## Steps

1. With Compatibility Mode off, assert leftover POST keys are not copied.
2. Enable Compatibility Mode and copy leftover admin AJAX POST keys.
3. Assert canonical keys receive leftover values while leftover keys remain.
4. With Compatibility Mode on, enqueue public compat assets and assert the JS
   globals bridge script registers.
5. With Compatibility Mode off, assert the bridge script is absent.

## Expected result

Leftover admin AJAX POST keys and the `sc_tax_settings` JS alias are absent
while Compatibility Mode is off and active while on.

## Edge cases

- Canonical POST keys win when both canonical and leftover are present.
- Pro may still localize `sc_tax_settings` until Pro matches Free 61.
