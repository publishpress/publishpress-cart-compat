# PPCart_Stripe registers NCS_Cart_Stripe and NCS_Stripe aliases when Compatibility Mode is on

## Scenario

After the #629 helper rename, `PPCart_Stripe` is the canonical Stripe service class. Third-party plugins that still reference `NCS_Cart_Stripe` or bare `NCS_Stripe` must receive working aliases when Compatibility Mode is enabled.

## Steps

1. Enable `_ppcart_studiocart_compatibility_mode`.
2. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
3. Assert `class_exists( 'PPCart_Stripe', false )`, `class_exists( 'NCS_Cart_Stripe', false )`, and `class_exists( 'NCS_Stripe', false )`.
4. Construct `new NCS_Cart_Stripe()` and `new NCS_Stripe()` and assert each is an instance of `PPCart_Stripe`.

## Expected result

All three class names resolve to the same canonical Stripe service when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (`test_IT_191_PPCart_Stripe_legacy_aliases_unregistered_when_mode_is_off`), legacy names must not be registered even though `PPCart_Stripe` is loaded.
