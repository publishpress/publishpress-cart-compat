# Leftover tax-rate inner keys copy only when Compatibility Mode is on

## Scenario

Sites that still store leftover `_sc_tax_rate_*` inner keys in
`_ppcart_tax_rates` must reach first-party `_ppcart_tax_rate_*` keys only
while Compatibility Mode is on. Mode off leaves the leftover keys unread.
The option row is not rewritten.

## Steps

1. Store leftover `_sc_tax_rate_*` keys in `_ppcart_tax_rates`.
2. Read via `ppcart_get_tax_data()` with Compatibility Mode off and confirm
   the leftover shape is not resolved.
3. Enable Compatibility Mode and read again.
4. Confirm the getter returns canonical bag keys and `get_option` still has
   leftover inner keys only.

## Expected result

Leftover inner keys copy onto canonical keys only while Compatibility Mode
is on. Stored option rows are not rewritten.

## Edge cases

- Canonical keys win when both leftover and canonical keys are present.
- Custom table columns `tax_rate_title` are not this family.
- `pre_update_option__ppcart_tax_rates` still points at missing
  `validate_custom_tax`; the test removes that filter so it can seed the
  leftover option row.
