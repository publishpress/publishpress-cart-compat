# Leftover studiocart theme copies resolve only when Compatibility Mode is on

## Scenario

Merchants who copied templates to `yourtheme/studiocart/` must keep those
overrides only while Compatibility Mode is on. Mode off ignores the leftover
directory. A canonical `yourtheme/publishpress-cart/` copy always wins.
Theme files are not copied or renamed on disk.

## Steps

1. Write a leftover `studiocart/` marker under `get_stylesheet_directory()`.
2. Resolve via `ppcart_get_template_path()` with Compatibility Mode off.
3. Enable Compatibility Mode and resolve again.
4. Add a canonical `publishpress-cart/` marker and confirm it wins.

## Expected result

Leftover theme copies resolve only while Compatibility Mode is on. Canonical
theme files win when both exist. Stored theme files stay in place.

## Edge cases

- Missing leftover and canonical files fall through to plugin templates.
- First-party loaders never look in `studiocart/` themselves.
