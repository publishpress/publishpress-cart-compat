# Data migration rewrites the leftover email identity merge tag

## Scenario

A merchant may explicitly migrate stored email templates after moving from the
StudioCart identity to PublishPress Cart.

## Steps

1. Store `Powered by {studiocart}` in the canonical email template option.
2. Run the existing merchant-triggered shortcode/tag migration to completion.
3. Read the email template option.

## Expected result

The stored value becomes `Powered by {publishpress_cart}`. The existing backup
supports restore, and migration is not triggered by activation or normal boot.
