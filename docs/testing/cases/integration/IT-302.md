# Data migration alters leftover order item meta object-id column

## Scenario

Metadata type `ncs_order_item` and column `ncs_order_item_id` migrate together. After `RENAME TABLE` of `ncs_order_itemmeta`, the migrator `ALTER`s `ncs_order_item_id` to `ppcart_order_item_id` on the canonical table only.

## Steps

1. Create leftover order item meta with column `ncs_order_item_id`.
2. Run `ppcart_migrate_custom_tables()`.
3. Inspect columns on `{prefix}ppcart_order_itemmeta`.

## Expected result

Canonical meta table has `ppcart_order_item_id` and no longer has `ncs_order_item_id`. `ppcart_live_metadata_type()` returns `ppcart_order_item`.

## Edge cases

- ALTER does not run on a leftover table that was not renamed.
