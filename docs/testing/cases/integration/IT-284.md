# Data migration rewrites leftover shortcode tags in posts and email options

## Scenario

The merchant Data migration rewrites leftover shortcode tags in stored post
content and email option HTML. Compatibility Mode still owns leftover
`add_shortcode()` registration.

## Steps

1. Insert a page containing `[studiocart-form]` and run the migrator.
2. Store leftover `[studiocart-order-downloads]` in an email body option and migrate.
3. Confirm leftover tags are still unregistered while Compatibility Mode is off.

## Expected result

The page content becomes `[ppcart_form…]`. The email option becomes
`[ppcart_order_downloads]`. Leftover tags are not `add_shortcode()`-registered
with the mode off.

## Edge cases

- Restore writes the backed-up original strings back.
