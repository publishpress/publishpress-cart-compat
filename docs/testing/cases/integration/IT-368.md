# Leftover checkout coupon and plan URLs redirect only when Compatibility Mode is on

## Scenario

Bookmarked `?coupon=` and `?plan=` checkout URLs must 302 to
`ppcart-coupon` and `ppcart-pay-plan` only while Compatibility Mode is on.
Account leftover `sc-plan` still 302s to `ppcart-plan`.

## Steps

1. With Compatibility Mode off, leftover `coupon` / `plan` are not
   registered.
2. Enable Compatibility Mode and confirm leftover registration.
3. Canonicalize `?coupon=` and `?plan=` while keeping an unrelated GET key.
4. Canonicalize leftover checkout `plan` and leftover account `sc-plan` in
   one URL.
5. Confirm canonical-only URLs do not redirect again.

## Expected result

Mode off leaves leftover checkout args unregistered. Mode on 302s them to
prefixed keys, preserves extra GET keys, and keeps account `ppcart-plan`
distinct from checkout `ppcart-pay-plan`.

## Edge cases

- Merge after Cart hard-cutover in publishpress-cart#753. Until then Cart
  still registers unprefixed `coupon` / `plan`.
- Canonical values win when both leftover and prefixed keys are present.
