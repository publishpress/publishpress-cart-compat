# Custom table migration preserves leftover rows

## Scenario

`RENAME TABLE` must keep existing tax-rate, order-item, and download rows. The migration is a name change, not a copy-and-drop of data.

## Steps

1. Insert distinct marker rows into leftover tax, order items, and downloads tables.
2. Run `ppcart_migrate_custom_tables()`.
3. Read the same keys from the canonical tables.

## Expected result

Each marker row is present on the canonical table with the same values.

## Edge cases

- Empty leftover tables still rename successfully.
