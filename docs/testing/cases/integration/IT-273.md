# Seed marks canonical only when leftover detection is empty

## Scenario

Activate/upgrade seed never renames rows. A site with no leftover CPT,
taxonomy, role, or capability strings is marked canonical. A leftover
capability on a throwaway role, or leftover `sc_cart_manager`, keeps seed
in legacy mode.

## Steps

1. Delete the migration option on a clean site and call
   `ppcart_cpt_slug_migration_maybe_seed_state()`.
2. Add `sc_manager_option` to a throwaway role, delete the option, and seed.
3. Add leftover `sc_cart_manager`, delete the option, and seed.

## Expected result

Clean seed writes `mode=canonical` with both steps complete. Leftover cap or
role seed writes `mode=legacy` and leaves step 1 incomplete.

## Edge cases

- WPLoader activate seeds canonical before `add_cap()`, so leftover roles
  are not present until a test injects them.
