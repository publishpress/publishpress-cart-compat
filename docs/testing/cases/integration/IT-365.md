# Leftover affiliate cookies copy only when Compatibility Mode is on

## Scenario

A leftover `sc_affiliate_id` cookie must fill `ppcart_affiliate_id` only while
Compatibility Mode is on. The leftover cookie stays. There is no silent
migrate and no option/meta row copy.

## Steps

1. Set `$_COOKIE['sc_affiliate_id']` with Compatibility Mode off and copy.
2. Confirm canonical is absent.
3. Enable Compatibility Mode and copy again.
4. Confirm canonical equals leftover and leftover remains.

## Expected result

Leftover affiliate cookies copy onto `ppcart_affiliate_id` only while
Compatibility Mode is on.

## Edge cases

- Canonical wins when both cookies are present (UT-312).
- Unprefixed `affiliate_id` is a leftover name on the same map.
