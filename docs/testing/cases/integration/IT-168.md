# PPCart_Order_Item registers NCS_Cart_Order_Item and ScrtOrderItem aliases when Compatibility Mode is on

## Scenario

After the #629 model rename, `PPCart_Order_Item` is the canonical order line-item class. Legacy callers using `NCS_Cart_Order_Item` or `ScrtOrderItem` must keep working when Compatibility Mode is enabled.

## Steps

1. Require the order item classes if they are not already loaded.
2. Enable `_ppcart_compatibility_mode`.
3. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
4. Assert `class_exists( 'PPCart_Order_Item', false )`, `class_exists( 'NCS_Cart_Order_Item', false )`, and `class_exists( 'ScrtOrderItem', false )`.
5. Construct `new NCS_Cart_Order_Item()` and `new ScrtOrderItem()` and assert each is an instance of `PPCart_Order_Item`.

## Expected result

All three class names resolve to the same canonical order item model when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (`test_IT_168_PPCart_Order_Item_legacy_aliases_unregistered_when_mode_is_off`), legacy order item names must not be registered.
