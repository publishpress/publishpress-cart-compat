# Leftover shortcode tags enqueue and replace in email only when Compatibility Mode is on

## Scenario

Asset enqueue treats a leftover stored form tag as a hit. Email HTML always
replaces `[ppcart_order_downloads]` and replaces leftover
`[studiocart-order-downloads]` only while Compatibility Mode is on.

## Steps

1. Put a leftover form tag in a page and check frontend-asset detection.
2. Build a notification email with both download tags, mode off then on.

## Expected result

Enqueue hits leftover openings. With the mode off, leftover email tags stay in
the body; with the mode on they are replaced.

## Edge cases

- Leftover email replace is not an `add_shortcode()` shim.
- Enqueue leftover detection does not require leftover tags to be registered.
