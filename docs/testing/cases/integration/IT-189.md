# PPCart_Helper registers NCS_Cart_Helper and NCS_Helper aliases when Compatibility Mode is on

## Scenario

After the #629 helper rename, `PPCart_Helper` is the canonical helper class. Third-party plugins that still reference `NCS_Cart_Helper` or bare `NCS_Helper` must receive working aliases when Compatibility Mode is enabled.

## Steps

1. Enable `_ppcart_studiocart_compatibility_mode`.
2. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
3. Assert `class_exists( 'PPCart_Helper', false )`, `class_exists( 'NCS_Cart_Helper', false )`, and `class_exists( 'NCS_Helper', false )`.
4. Construct `new NCS_Cart_Helper()` and `new NCS_Helper()` and assert each is an instance of `PPCart_Helper`.

## Expected result

All three class names resolve to the same canonical helper when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (`test_IT_189_PPCart_Helper_legacy_aliases_unregistered_when_mode_is_off`), `NCS_Cart_Helper` and `NCS_Helper` must not be registered even though `PPCart_Helper` is loaded.
