# Leftover log GET and nonce fields copy only when Compatibility Mode is on

## Scenario

Bookmarked leftover `sc_view_log` / `sc_view_debug_log_nonce` must reach
first-party canonical keys only while Compatibility Mode is on. Mode off
leaves leftover keys unread.

## Steps

1. Set leftover GET `sc_view_log` and `sc_view_debug_log_nonce` with
   Compatibility Mode off and confirm canonical keys are absent.
2. Enable Compatibility Mode and copy again.
3. Confirm canonical keys are filled and leftover keys remain.

## Expected result

Leftover log viewer GET/nonce keys copy onto `ppcart_view_log` /
`ppcart_view_debug_log_nonce` only while Compatibility Mode is on.

## Edge cases

- Canonical wins when both leftover and canonical keys are present.
- Leftover keys stay in the request (no silent delete).
