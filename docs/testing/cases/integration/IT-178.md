# Compatibility Mode registers Gutenberg class aliases

## Scenario

After each Gutenberg class is confirmed canonical with Compatibility Mode off, enabling the feature must register every `NCS_Cart_*` Gutenberg alias from `maps/gutenberg.php`.

## Steps

1. Run after IT-177 so no Gutenberg legacy aliases are registered yet.
2. Assert `PPCart_Product_Template` exists and `NCS_Cart_Product_Template` does not.
3. Enable `_ppcart_compatibility_mode` and call `maybe_register_aliases()`.
4. For each Gutenberg pair in the map, assert the legacy name aliases the canonical class.
5. Construct each legacy Gutenberg class and assert it is an instance of the matching `PPCart_*` class.

## Expected result

All nine Gutenberg legacy names alias their canonical `PPCart_*` classes when Compatibility Mode is on.
