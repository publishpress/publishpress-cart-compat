# Leftover GET sc-slm-order copies only while Compatibility Mode is on

## Scenario

Cart reads canonical GET `ppcart-slm-order`. Compatibility Mode copies leftover
`sc-slm-order` onto that key while the toggle is on.

## Steps

1. With Compatibility Mode off, assert leftover GET is not copied.
2. Enable Compatibility Mode and copy leftover GET `sc-slm-order`.
3. Assert the canonical key receives the leftover value while the leftover key
   remains.

## Expected result

Leftover GET `sc-slm-order` is absent from canonical keys while Compatibility
Mode is off and copied while on.

## Edge cases

- Canonical GET wins when both `ppcart-slm-order` and `sc-slm-order` are present.
- Cart first-party never reads leftover `sc-slm-order` (UT-297).
