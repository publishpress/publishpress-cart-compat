# PPCart_Order_Helper registers NCS_Cart_Order_Helper and NCS_Order_Helper aliases when Compatibility Mode is on

## Scenario

After the #629 helper rename, `PPCart_Order_Helper` is the canonical order helper class. Third-party plugins that still reference `NCS_Cart_Order_Helper` or bare `NCS_Order_Helper` must receive working aliases when Compatibility Mode is enabled.

## Steps

1. Enable `_ppcart_compatibility_mode`.
2. Call `PPCart_Studiocart_Compatibility_Mode::maybe_register_aliases()`.
3. Assert `class_exists( 'PPCart_Order_Helper', false )`, `class_exists( 'NCS_Cart_Order_Helper', false )`, and `class_exists( 'NCS_Order_Helper', false )`.
4. Construct `new NCS_Cart_Order_Helper()` and `new NCS_Order_Helper()` and assert each is an instance of `PPCart_Order_Helper`.

## Expected result

All three class names resolve to the same canonical order helper when Compatibility Mode is on.

## Edge cases

- With Compatibility Mode off (`test_IT_190_PPCart_Order_Helper_legacy_aliases_unregistered_when_mode_is_off`), legacy names must not be registered even though `PPCart_Order_Helper` is loaded.
