# Checkout preview controller registers NCS_Cart_Checkout_Preview_Controller alias when Compatibility Mode is on

## Scenario

Third-party code that still references `NCS_Cart_Checkout_Preview_Controller` must resolve to the canonical `PPCart_Checkout_Preview_Controller` when Compatibility Mode is enabled.

## Steps

1. In an isolated process with Compatibility Mode off, assert `PPCart_Checkout_Preview_Controller` exists and `NCS_Cart_Checkout_Preview_Controller` does not.
2. Enable `_ppcart_studiocart_compatibility_mode` and call `maybe_register_aliases()`.
3. Assert both class names exist and `new NCS_Cart_Checkout_Preview_Controller(...)` is a `PPCart_Checkout_Preview_Controller`.

## Expected result

The legacy checkout preview controller name aliases the canonical class only when Compatibility Mode is on.
