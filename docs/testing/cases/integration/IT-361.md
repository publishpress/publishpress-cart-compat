# Leftover sc-uploads root allowed only while Compatibility Mode is on

## Scenario

Cart allow-lists `ppcart-uploads` only. Compatibility Mode adds leftover
`sc-uploads` as an extra allowed root while the toggle is on. Existing files
under the leftover directory stay in place; nothing is copied or moved.

## Steps

1. Create a leftover `sc-uploads` file under the uploads basedir.
2. With Compatibility Mode off, assert the leftover root is absent and the
   leftover file does not resolve.
3. Enable Compatibility Mode and register the extra-root bridge.
4. Assert the leftover root is allowed and the leftover file resolves.
5. Assert the leftover file was not copied into `ppcart-uploads`.

## Expected result

Leftover `sc-uploads` is absent from allowed roots while Compatibility Mode is
off and present while on. No silent file move.

## Edge cases

- Canonical `ppcart-uploads` remains allowed with Compat on or off.
- Cart first-party never emits leftover `sc-uploads` (UT-308).
