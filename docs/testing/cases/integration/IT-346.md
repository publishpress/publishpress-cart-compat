# Leftover GET sc_extension_notice copies only when Compatibility Mode is on

## Scenario

Addon redirects that still use leftover GET `sc_extension_notice` must reach
first-party `ppcart_extension_notice` only while Compatibility Mode is on.
Mode off leaves the leftover key unread.

## Steps

1. Set leftover GET `sc_extension_notice` with Compatibility Mode off and
   confirm `ppcart_extension_notice` is absent.
2. Enable Compatibility Mode and copy again.
3. Confirm canonical `ppcart_extension_notice` is filled and leftover
   `sc_extension_notice` remains.

## Expected result

Leftover GET `sc_extension_notice` copies onto `ppcart_extension_notice`
only while Compatibility Mode is on.

## Edge cases

- Canonical wins when both leftover and canonical keys are present.
- Leftover keys stay in the request (no silent delete).
