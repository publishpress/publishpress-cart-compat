# PPCart_Debug_Logger is canonical under Compatibility Mode prefix rename

## Scenario

Issue #629 set 7 renames stripe sync, logging, secrets, and files classes to `PPCart_*`. The matching `NCS_Cart_*` name must exist only when StudioCart Compatibility Mode is enabled.

## Steps

1. Boot the integration suite with Compatibility Mode off.
2. Assert the canonical `PPCart_*` class is loaded.
3. Assert the legacy `NCS_Cart_*` name is not registered via `class_alias` while the feature is off.

## Expected result

`class_exists('PPCart_*', false)` is true and `class_exists('NCS_Cart_*', false)` is false with Compatibility Mode off.

## Edge cases

- IT-227 runs alias registration after the individual canonical checks; do not enable Compatibility Mode in IT-220 through IT-226.
