# PPCart_Paypal is canonical under Compatibility Mode prefix rename

## Scenario

Issue #629 set 3 renames public-facing classes to `PPCart_Paypal`. `NCS_Cart_Paypal` must exist only when StudioCart Compatibility Mode is enabled.

## Steps

1. Boot the integration suite with Compatibility Mode off.
2. Assert `PPCart_Paypal` is loaded as the canonical class.
3. Assert `NCS_Cart_Paypal` is not registered via `class_alias` while the feature is off.

## Expected result

`class_exists('PPCart_Paypal', false)` is true and `class_exists('NCS_Cart_Paypal', false)` is false with Compatibility Mode off.

## Edge cases

- IT-188 runs alias registration after this case; do not enable Compatibility Mode here.
