# Compatibility Mode registers public-facing NCS_Cart_* class aliases

## Scenario

Issue #629 set 3 renames public-facing classes to `PPCart_Public_Subscription_Checkout_Controller`. `NCS_Cart_Public_Subscription_Checkout_Controller` must exist only when StudioCart Compatibility Mode is enabled.

## Steps

1. Boot the integration suite with Compatibility Mode off.
2. Assert `PPCart_Public_Subscription_Checkout_Controller` is loaded as the canonical class.
3. Assert `NCS_Cart_Public_Subscription_Checkout_Controller` is not registered via `class_alias` while the feature is off.
4. Enable Compatibility Mode and call `maybe_register_aliases()`.
5. Assert every public class in `maps/public.php` aliases correctly, including `new NCS_Cart_Public()` instanceof `PPCart_Public`.

## Expected result

All ten public class pairs from `maps/public.php` register working legacy aliases when Compatibility Mode is on.

## Edge cases

- Depends on IT-187 because `class_alias` cannot be undone in-process.
