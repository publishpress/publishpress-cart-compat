# Data migration renames leftover custom tables to canonical names

## Scenario

The opt-in Data migration step runs `RENAME TABLE` from leftover `ncs_*` names to canonical `ppcart_*` names. Plugin upgrade does not do this; only `ppcart_migrate_custom_tables()` does.

## Steps

1. Create leftover tables and drop canonical tables.
2. Run `ppcart_migrate_custom_tables()`.
3. Check leftover vs canonical table existence and live helper output.

## Expected result

Leftover tables are gone, canonical tables exist, and `ppcart_live_table()` returns canonical names.

## Edge cases

- Families that are already canonical are skipped, not dropped.
