# Compatibility Mode class is canonical and the unreleased name stays undefined

## Scenario

`NCS_Cart_Studiocart_Compatibility_Mode` was never released, so Compatibility Mode must not alias it. After WordPress boots with Cart active, only `PPCart_Studiocart_Compatibility_Mode` exists.

## Steps

1. Boot the integration suite (plugin active).
2. Assert `class_exists( 'PPCart_Studiocart_Compatibility_Mode', false )`.
3. Assert `class_exists( 'NCS_Cart_Studiocart_Compatibility_Mode', false )` is false.

## Expected result

The canonical manager class is loaded. The unreleased old name is undefined, including when Compatibility Mode is later enabled.

## Edge cases

- Unlike other `NCS_Cart_*` classes, this name must not appear in `maps/*.php`.
