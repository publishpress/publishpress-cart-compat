# Account styles registers NCS_Cart_Account_Styles alias when Compatibility Mode is on

## Scenario

Third-party code that still references `NCS_Cart_Account_Styles` must resolve to the canonical `PPCart_Account_Styles` when Compatibility Mode is enabled.

## Steps

1. In an isolated process with Compatibility Mode off, assert `PPCart_Account_Styles` exists and `NCS_Cart_Account_Styles` does not.
2. Enable `_ppcart_studiocart_compatibility_mode` and call `maybe_register_aliases()`.
3. Assert both class names exist and `new NCS_Cart_Account_Styles()` is a `PPCart_Account_Styles`.

## Expected result

The legacy account styles name aliases the canonical class only when Compatibility Mode is on.
