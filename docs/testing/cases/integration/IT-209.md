# PPCart_Admin_Order_List_Controller is canonical under Compatibility Mode prefix rename

## Scenario

Issue #629 set 6 renames admin controller and dashboard classes to `PPCart_Admin_Order_List_Controller`. `NCS_Cart_Admin_Order_List_Controller` must exist only when StudioCart Compatibility Mode is enabled.

## Steps

1. Boot the integration suite with Compatibility Mode off.
2. Assert `PPCart_Admin_Order_List_Controller` is loaded as the canonical class.
3. Assert `NCS_Cart_Admin_Order_List_Controller` is not registered via `class_alias` while the feature is off.

## Expected result

`class_exists('PPCart_Admin_Order_List_Controller', false)` is true and `class_exists('NCS_Cart_Admin_Order_List_Controller', false)` is false with Compatibility Mode off.

## Edge cases

- IT-219 runs alias registration after the individual canonical checks; do not enable Compatibility Mode in IT-208 through IT-218.
