# Leftover POST sc_qty copies only when Compatibility Mode is on

## Scenario

Custom leftover checkout forms that still POST `sc_qty` must reach
first-party `ppcart_qty` only while Compatibility Mode is on. Mode off
leaves the leftover key unread.

## Steps

1. Set leftover POST `sc_qty` with Compatibility Mode off and confirm
   `ppcart_qty` is absent.
2. Enable Compatibility Mode and copy again.
3. Confirm canonical `ppcart_qty` is filled and leftover `sc_qty` remains.

## Expected result

Leftover POST `sc_qty` copies onto `ppcart_qty` only while Compatibility
Mode is on.

## Edge cases

- Canonical wins when both leftover and canonical keys are present.
- Leftover keys stay in the request (no silent delete).
