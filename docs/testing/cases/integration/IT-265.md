# Plugin identity strings use canonical prefixes with legacy hook bridges

## Scenario

Runtime plugin identity is `ppcart`. Currency filters use canonical
`ppcart_*` hooks, and hooks derived from the runtime identity use `ppcart-*`.
Their shipped `ncs-cart-*` names remain available only through StudioCart
Compatibility Mode.

## Steps

1. Assert the core class assigns `ppcart`, not `ncs-cart`, as runtime identity.
2. With Compatibility Mode off, fire canonical currency and dynamic
   plugin-identity filters.
3. Enable Compatibility Mode and fire canonical filters while listening on
   their shipped `ncs-cart-*` names.
4. Fire the legacy names while listening on the canonical hooks.

## Expected result

Runtime identity is `ppcart`. Legacy listeners do not run while Compatibility
Mode is off. With the mode on, the three currency filters and generic
hyphenated plugin-identity hooks bridge in both directions without changing the
filter value contract.

## Edge cases

- Canonical wp-admin screen and menu slugs use the `ppcart` family and are not
  Compatibility Mode hook identities.
