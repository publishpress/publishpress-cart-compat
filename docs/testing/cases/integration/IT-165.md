# StudioCart submenu owns the Compatibility Mode option

## Scenario

Merchants toggle Compatibility Mode from Cart → StudioCart
(`page=ppcart-studiocart`), not Cart Settings. The option id stays
`_ppcart_compatibility_mode`. The old `_ppcart_option_list`
settings field is gone.

## Steps

1. Assert `_ppcart_option_list` is not hooked to Compatibility Mode
   `register_settings`.
2. Assert `PPCartComp_Studiocart_Admin::PAGE_SLUG` is `ppcart-studiocart`.
3. Assert the option constant is `_ppcart_compatibility_mode`.
4. Assert Cart Settings has no `ppcart-compatibility` section.

## Expected result

The toggle lives on the StudioCart submenu. Cart Settings does not register
a Compatibility Mode section.

## Edge cases

- The option string is shared with Cart first-party scanners that must not
  load this plugin's class.
