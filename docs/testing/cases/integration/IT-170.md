# Gutenberg bootstrap registers NCS_Cart_Gutenberg_Bootstrap alias when Compatibility Mode is on

## Scenario

Third-party code that still references `NCS_Cart_Gutenberg_Bootstrap` must resolve to the canonical `PPCart_Gutenberg_Bootstrap` when Compatibility Mode is enabled.

## Steps

1. In an isolated process with Compatibility Mode off, assert `PPCart_Gutenberg_Bootstrap` exists and `NCS_Cart_Gutenberg_Bootstrap` does not.
2. Enable `_ppcart_compatibility_mode` and call `maybe_register_aliases()`.
3. Assert both class names exist and `new NCS_Cart_Gutenberg_Bootstrap()` is a `PPCart_Gutenberg_Bootstrap`.

## Expected result

The legacy Gutenberg bootstrap name aliases the canonical class only when Compatibility Mode is on.
