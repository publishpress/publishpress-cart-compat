# Canonical AJAX actions accept gated legacy routes and nonces

## Scenario

Core registers `wp_ajax_ppcart_*` routes and generates `ppcart_*` nonce
actions. Compatibility Mode dual-registers the shipped StudioCart POST
actions and accepts mapped legacy nonce strings without changing request
field names.

## Steps

1. Confirm canonical checkout and admin AJAX hooks are registered.
2. Confirm legacy `wp_ajax_sc_*` / `wp_ajax_ncs_*` hooks are absent while the
   mode is off.
3. Enable Compatibility Mode and verify legacy hooks appear with the same
   auth/nopriv exposure as the canonical contract.
4. Create a canonical nonce and verify it with Compatibility Mode off.
5. Create a mapped legacy nonce and verify it only after the mode is on.

## Expected result

First-party code answers `ppcart_*` AJAX actions in both modes. Legacy POST
actions and nonce strings work only while Compatibility Mode is enabled.
Auth-only actions do not gain unauthenticated routes.

## Edge cases

- `ppcart_json_search_user` stays authenticated-only.
- A prefix nonce such as `sc_duplicate_product_{id}` verifies against
  `ppcart_duplicate_product_{id}` only when Compatibility Mode is on.
