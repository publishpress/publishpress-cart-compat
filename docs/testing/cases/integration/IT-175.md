# Account renderer registers NCS_Cart_Account_Renderer alias when Compatibility Mode is on

## Scenario

Third-party code that still references `NCS_Cart_Account_Renderer` must resolve to the canonical `PPCart_Account_Renderer` when Compatibility Mode is enabled.

## Steps

1. In an isolated process with Compatibility Mode off, assert `PPCart_Account_Renderer` exists and `NCS_Cart_Account_Renderer` does not.
2. Enable `_ppcart_compatibility_mode` and call `maybe_register_aliases()`.
3. Assert both class names exist and `new NCS_Cart_Account_Renderer()` is a `PPCart_Account_Renderer`.

## Expected result

The legacy account renderer name aliases the canonical class only when Compatibility Mode is on.
