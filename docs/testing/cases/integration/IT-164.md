# ppcart_cart_supports follows the Compatibility Mode option

## Scenario

Canonical Cart code and add-ons should ask `ppcart_cart_supports( 'studiocart-compatibility-mode' )` rather than reading the option. On a real WordPress site that filter must track `_ppcart_studiocart_compatibility_mode`, and must not change support for unrelated features such as `pro`.

## Steps

1. Set the option to `1` and call `ppcart_cart_supports( 'studiocart-compatibility-mode' )`.
2. Set the option to `0` and call it again.
3. Call `ppcart_cart_supports( 'pro' )` while the mode is on.

## Expected result

The StudioCart feature key is true when the option is `1` and false when it is `0`. `pro` is unchanged by the Compatibility Mode setting.

## Edge cases

- Priority 20 on `ppcart_cart_supports_feature` must win over Pro's blanket true when this suite runs under Free.
