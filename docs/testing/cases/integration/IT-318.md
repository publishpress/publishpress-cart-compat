# Leftover product-duplicate admin_action is dual-registered when Compatibility Mode is on

## Scenario

Core registers `admin_action_ppcart_duplicate_product`. Compatibility Mode dual-registers leftover `admin_action_sc_duplicate_product` onto the same handler.

## Steps

1. Confirm the canonical product-duplicate admin action is registered.
2. Confirm leftover `admin_action_sc_duplicate_product` is absent while Compatibility Mode is off.
3. Enable Compatibility Mode and register request-field bridges.
4. Confirm leftover `admin_action_sc_duplicate_product` is present.

## Expected result

First-party answers `admin_action_ppcart_duplicate_product` in both modes. Leftover `admin_action_sc_duplicate_product` works only while Compatibility Mode is on.

## Edge cases

- WordPress `action` is not rewritten by the request-field map.
