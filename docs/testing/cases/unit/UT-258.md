# Request-field map covers leftover checkout sc_qty

## Scenario

Slice 35 first-party reads POST `ppcart_qty`. Compatibility Mode must copy
leftover `sc_qty` onto that canonical key. Other slice-35 leftovers are
first-party hard cutovers (no extra map rows).

## Steps

1. Load `ncs_cart_get_legacy_request_field_map()`.
2. Assert `ppcart_qty` maps to leftover `sc_qty`.

## Expected result

The request-field map includes `ppcart_qty => [ 'sc_qty' ]`.

## Edge cases

- WordPress dispatcher key `action` stays unmapped.
- Leftover `sc_custom_fields` / `sc_accept_terms` were already mapped in
  slice 26.
