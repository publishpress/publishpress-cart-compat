# Admin AJAX request-field map and JS globals bridge cover leftover keys

## Scenario

Compatibility Mode must map leftover admin AJAX POST keys and alias the
`sc_tax_settings` JS global onto `ppcart_tax_settings` while the toggle is on.

## Steps

1. Load `ncs_cart_get_legacy_request_field_map()`.
2. Assert `ppcart_ajax_nonce` and `ppcart_action` list leftover keys.
3. Copy leftover POST keys with Compatibility Mode on and assert canonical keys
   receive values.
4. Assert the JS globals bridge references `sc_tax_settings` and
   `ppcart_tax_settings`.

## Expected result

The request-field map and JS bridge source cover leftover admin AJAX keys and
`sc_tax_settings`.

## Edge cases

- Canonical POST keys win when both are set.
- Bridge script enqueues only while Compatibility Mode is on (IT-352).
