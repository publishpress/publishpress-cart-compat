# First-party PHP uses canonical integration service ids

## Scenario

Prefix slice 49 switches leftover integration `services` ids in Cart. Shared
catalog id — leftover `services` copy lives in Compat (UT-283 / IT-347).

## Steps

1. Cart unit `IntegrationServiceIdsTest` scans first-party PHP.
2. This Compat case documents the reserved id.

## Expected result

- Cart first-party uses `ppcart_subscription` / `ppcart_refund_order` /
  `ppcart_wpdomainchecker` only.
- Leftover `services` values copy only while Compatibility Mode is on.

## Edge cases

- CPT leftover `sc_subscription` is a different family.
