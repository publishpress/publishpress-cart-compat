# Leftover checkout coupon and plan query args map onto prefixed keys

## Scenario

StudioCart checkout URLs used unprefixed `?coupon=` and `?plan=`. Cart
canonical names are `ppcart-coupon` and `ppcart-pay-plan`. Account
subscription routing stays `sc-plan` → `ppcart-plan`. Compatibility Mode
must map both leftover checkout args without colliding with the account
plan key.

## Steps

1. Map a request that has leftover `coupon`, leftover `plan`, and leftover
   `sc-plan`.
2. Map a request that already has canonical `ppcart-coupon` /
   `ppcart-pay-plan` plus leftover `coupon` / `plan`.

## Expected result

Leftover checkout args become `ppcart-coupon` and `ppcart-pay-plan`.
Leftover `sc-plan` still becomes `ppcart-plan`. Canonical checkout keys
win; leftover keys are still listed so the 302 can strip them.

## Edge cases

- Depends on Cart reading `ppcart-pay-plan` / `ppcart-coupon` after
  publishpress-cart#753.
- Array-shaped leftover values stay ignored (UT-198).
