# First-party fires and looks up canonical leftover-family hooks

## Scenario

Prefix slice 44 switches leftover hook fires and preload lookups to canonical
`ppcart_*` names. Cart never inspects leftover `before_sc_*` / `sc_*` /
`studiocart_*` hook names.

## Steps

1. Read `ppcart_order_refund()` and payment-intent preload templates.
2. Read checkout and PayPal process-payment templates and the public hook registrar.
3. Scan first-party PHP under `admin/`, `includes/`, `public/`, and `models/`.
4. Assert canonical names are present and leftover slice-44 strings are absent.

## Expected result

- Refund fires `ppcart_before_order_refund`.
- Preload inspects canonical `ppcart_*` hooks and `ppcart_maybe_show_upsell`.
- Payment Element mount removes callbacks from `ppcart_before_create_main_order`.
- Checkout/PayPal fire `ppcart_checkout_complete` and filter `ppcart_show_upsell`.
- First-party PHP has no leftover slice-44 names.

## Edge cases

- Leftover listeners run only while Compatibility Mode is on (UT-276 / IT-345).
- Do not merge `ppcart_checkout_complete` into `ppcart_after_order_paid`.
