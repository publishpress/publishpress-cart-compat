# Compatibility Mode off ignores legacy constants

## Scenario

When Compatibility Mode is off, core reads only `PPCART_*` names. A leftover `NCS_CART_*` wp-config constant is ignored, and canonical values are not aliased to legacy names.

## Steps

1. Leave Compatibility Mode off.
2. Define `NCS_CART_LOADED_BY_PRO` and `PPCART_PRO_PLUGIN_NAME`.
3. Call `maybe_register_constants()`.

## Expected result

`PPCART_LOADED_BY_PRO` stays undefined and `NCS_CART_PRO_PLUGIN_NAME` stays undefined.
