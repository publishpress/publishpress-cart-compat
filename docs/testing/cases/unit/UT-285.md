# Leftover option names are sensitive only via Compatibility Mode filters

## Scenario

Slice 50 first-party treats `_ppcart_*` option names as secrets. Compatibility
Mode must append leftover `_sc_*` counterparts and mark leftover secret names
sensitive only while the mode is on.

## Steps

1. Copy canonical names through `ppcart_append_legacy_sensitive_option_names()`.
2. Assert leftover counterparts are added and leftover regex names match.
3. With Compatibility Mode off, `ppcart_maybe_*` helpers leave leftover names
   unmarked.
4. Enable Compatibility Mode and assert leftover secret names are marked.

## Expected result

- `_ppcart_mailchimp_api` copies to leftover `_sc_mailchimp_api`.
- Leftover `_sc_custom_api_key` is sensitive; leftover `_sc_currency` is not.
- Maybe-helpers are no-ops while Compatibility Mode is off.

## Edge cases

- Canonical names already marked sensitive stay sensitive.
- Stored leftover option rows are not rewritten.
