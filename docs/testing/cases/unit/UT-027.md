# Class alias is skipped when the canonical class is missing

## Scenario

`ncs_cart_register_class_alias()` can only alias a class that actually exists. When the canonical target class is not loaded, the registrar must silently skip creating the legacy alias instead of producing a broken or empty alias.

## Steps

1. Do not declare the canonical class `NCS_Cart_CompatAliasMissing` (it is intentionally absent).
2. Leave legacy compatibility enabled (default).
3. Call `ncs_cart_register_class_alias('NCS_Cart_CompatAliasMissing', 'CompatAliasLegacyMissing')`.

## Expected result

`class_exists('CompatAliasLegacyMissing', false)` returns `false` — no alias is created because the canonical class does not exist.

## Edge cases

- The registrar must not autoload or fatally error when the canonical class is missing; it simply does nothing.
