# Legacy compatibility can be disabled via filter

## Scenario

The `ncs_cart_legacy_compat_enabled` filter lets site owners turn off legacy alias registration at runtime. When a callback hooked to that filter returns `false`, the `ncs_cart_legacy_compat_enabled()` toggle must honor it and report compatibility as off, overriding the default-on behavior.

## Steps

1. Register a stub `ncs_cart_legacy_compat_enabled` filter (via the test's `compat_filters` state) whose callback returns `false`.
2. Call `ncs_cart_legacy_compat_enabled()`.

## Expected result

`ncs_cart_legacy_compat_enabled()` returns `false`, because the filtered value (`false`) replaces the default `true`.

## Edge cases

- A filter that returns `false` must win even though the constant `NCS_CART_LEGACY_COMPAT` is not defined.
