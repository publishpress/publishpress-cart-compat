# Hook bridge helpers and registration flags

## Scenario

Runtime hook bridges derive canonical `ppcart_*` / `_ppcart_*` and
plugin-identity `ppcart-*` names from legacy StudioCart hook names, exclude
frozen WordPress hooks, and register cron drain bridges always while legacy
hook bridges register only when Compatibility Mode is on.

## Steps

1. Assert legacy => canonical and canonical => legacy helpers for `sc_*`,
   `_sc_*`, `ncs_*`, `studiocart_*`, and generic `ncs-cart-*` names.
2. Assert the three shipped `ncs-cart-*` currency filters map to their
   canonical underscore names.
3. Assert frozen AJAX and CPT hooks are excluded from mapping.
4. With Compatibility Mode off, register cron bridges and assert legacy hook
   bridges stay unregistered.
5. Enable Compatibility Mode and assert legacy hook bridges register.

## Expected result

Naming helpers and bridge registration follow the #629 hook compatibility design without legacy hook calls outside the Compatibility Mode package.
