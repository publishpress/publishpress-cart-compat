# Migration backups uninstall setting defaults off and sanitizes

## Scenario

Cart → StudioCart registers `ppcartcomp_drop_migration_backups_on_uninstall` on the `ppcartcomp_studiocart` Settings API group. The default is off. Sanitize stores only `'1'` or `'0'`.

## Steps

1. Assert `PPCartComp_Studiocart_Admin::DROP_BACKUPS_OPTION` is `ppcartcomp_drop_migration_backups_on_uninstall`.
2. Call `sanitize_drop_backups()` with unset-like, `'0'`, `false`, `''`, `'1'`, and integer `1`.
3. Stub `register_setting()` and call `PPCartComp_Studiocart_Admin::register_setting()`.

## Expected result

Sanitize returns `'0'` except for `'1'` and integer `1`. The option registers on group `ppcartcomp_studiocart` with default `'0'` and the drop-backups sanitize callback.

## Edge cases

- Integer `1` from a direct `update_option` still sanitizes to `'1'`.
