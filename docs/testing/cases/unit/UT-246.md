# Saving the StudioCart page leaves the drop-backups uninstall option alone

## Scenario

Cart → StudioCart no longer shows a Migration backups box (publishpress/publishpress-cart-compat#24). The page form only saves Compatibility Mode. `ppcartcomp_drop_migration_backups_on_uninstall` stays readable by uninstall, so a stored `'1'` still drops the reverse-map tables.

## Steps

1. Assert `PPCartComp_Studiocart_Admin::DROP_BACKUPS_OPTION` is `ppcartcomp_drop_migration_backups_on_uninstall`.
2. Stub `register_setting()` and call `PPCartComp_Studiocart_Admin::register_setting()`.

## Expected result

Compatibility Mode registers on the `ppcartcomp_studiocart` group. The drop-backups option does not, so `options.php` never resets it to `'0'` when the merchant saves the page.

## Edge cases

- A site that opted in before this change keeps `'1'`, and uninstall still drops the backups.
