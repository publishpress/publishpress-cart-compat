# Compatibility Mode maps leftover checkout runtime globals

## Scenario

Compatibility Mode maps leftover `sc_checkout_request_rendered` and
`sc_checkout_block_arrangement` onto the canonical `ppcart_checkout_*` globals.

## Steps

1. Read `includes/compat/studiocart-compatibility-mode/globals.php`.
2. Assert the map lists leftover aliases for both checkout runtime keys.

## Expected result

The Compatibility Mode global map includes leftover checkout runtime names.

## Edge cases

- First-party Cart scanners for canonical names stay in PublishPress Cart
  (same case id, first-party half).
