# Public query-var map covers leftover webhook and invoice

## Scenario

Slice 43 first-party registers `ppcart-api` / `ppcart-invoice` and emits
`/ppcart-webhook/`. Compatibility Mode must map leftover `sc-api` /
`sc-invoice` for GET 302 and leftover `/sc-webhook/` rewrite plus POST copy
onto `ppcart-api`.

## Steps

1. Load `PPCartComp_Studiocart_Public_Query_Compatibility::legacy_query_var_map()`.
2. Load `leftover_webhook_rewrite()`.
3. Assert leftover rewrite registers only while Compatibility Mode is on.
4. Assert POST copies leftover `sc-api` onto `ppcart-api` and GET does not.

## Expected result

The public query-var map includes `sc-api => ppcart-api` and
`sc-invoice => ppcart-invoice`. Leftover rewrite is
`sc-webhook/?([^/]*)` → `index.php?ppcart-api=$matches[1]`. POST copy is
gated on Compatibility Mode; GET leftover query args 302 instead.

## Edge cases

- Redirect status stays 302 for safe GET/HEAD.
- Stripe/PayPal POSTs must not 302.
