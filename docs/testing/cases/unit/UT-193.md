# Developer kill switch suppresses outbound constant aliases

## Scenario

`NCS_CART_LEGACY_COMPAT` / `ncs_cart_legacy_compat_enabled()` remains the package-local developer/CI kill switch. When it is false, Compatibility Mode still copies inbound legacy wp-config values into canonical names, but it does not define outbound legacy aliases. The constant itself is covered by UT-031; this case uses the filter so it can run in the shared unit process.

## Steps

1. Disable `ncs_cart_legacy_compat_enabled` via the filter and enable Compatibility Mode.
2. Define `PPCART_STYLESHEET_PATH` and a legacy `NCS_CART_STRIPE_WEBHOOK_LOG_DIR`.
3. Call `maybe_register_constants()`.

## Expected result

`NCS_STYLESHEETPATH` stays undefined. `PPCART_STRIPE_WEBHOOK_LOG_DIR` is copied from the inbound legacy value.
