# Class alias is skipped when the legacy name already exists

## Scenario

`ncs_cart_register_class_alias()` must never clobber a class that already occupies the legacy name. If both the legacy name and the canonical name already exist as real classes, calling the registrar must leave the existing legacy class untouched rather than re-aliasing it to the canonical class.

## Steps

1. Declare a real global stub class `CompatAliasLegacyExisting`.
2. Declare a separate real global stub class `NCS_Cart_CompatAliasExisting`.
3. Call `ncs_cart_register_class_alias('NCS_Cart_CompatAliasExisting', 'CompatAliasLegacyExisting')`.

## Expected result

`is_a('CompatAliasLegacyExisting', 'NCS_Cart_CompatAliasExisting', true)` returns `false`, and `\CompatAliasLegacyExisting::class` is still `'CompatAliasLegacyExisting'` — the pre-existing legacy class is preserved and not turned into an alias.

## Edge cases

- The guard must protect a legacy class that already exists for an unrelated reason, preventing accidental override of third-party classes sharing the name.
