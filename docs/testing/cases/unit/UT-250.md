# Compatibility Mode maps leftover $scFiles / $sc_product_fields / $sc_is_studiocart_admin_screen

## Scenario

Compatibility Mode maps leftover `$scFiles`, `$sc_product_fields`, and
`$sc_is_studiocart_admin_screen` onto the canonical `$ppcart_files`,
`$ppcart_product_fields`, and `$ppcart_is_admin_screen` runtime globals.

## Steps

1. Read `includes/compat/studiocart-compatibility-mode/globals.php`.
2. Assert the map lists `'ppcart_files'` → `'scFiles'`,
   `'ppcart_product_fields'` → `'sc_product_fields'`, and
   `'ppcart_is_admin_screen'` → `'sc_is_studiocart_admin_screen'`.

## Expected result

The Compatibility Mode global map includes leftover `$scFiles`,
`$sc_product_fields`, and `$sc_is_studiocart_admin_screen` for the canonical
`$ppcart_*` names.

## Edge cases

- First-party Cart scanners for the canonical names stay in PublishPress Cart
  (UT-251).
