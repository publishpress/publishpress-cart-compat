# Settings checkbox is enabled when wp-config constant is undefined

## Scenario

When `PPCART_STUDIOCART_COMPATIBILITY_MODE` is not defined, the Compatibility Mode
checkbox in Cart settings is editable and has no wp-config note.

## Steps

1. Skip when the constant is already defined in the current process.
2. Call `PPCart_Studiocart_Compatibility_Mode::register_settings([])`.
3. Inspect the Compatibility Mode control's disabled state and wp-config note.

## Expected result

`disabled` is `false` and `note` is an empty string.
