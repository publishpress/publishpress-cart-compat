# wp-config constant true overrides disabled option

## Scenario

When `PPCART_STUDIOCART_COMPATIBILITY_MODE` is defined as `true` in wp-config.php,
Compatibility Mode is enabled even if the Settings option is saved as `0`.

## Steps

1. Define `PPCART_STUDIOCART_COMPATIBILITY_MODE` as `true` in an isolated process.
2. Stub `get_option` to return `'0'` for the Compatibility Mode option.
3. Call `is_wp_config_forced()`, `is_user_enabled()`, and `is_enabled()`.

## Expected result

`is_wp_config_forced()` is `true`; `is_user_enabled()` and `is_enabled()` are `true`.
