# Oldest Compatibility Mode option still enables without storage mutation

## Scenario

Sites that saved Compatibility Mode under the oldest `_sc_studiocart_compatibility_mode` key must stay enabled. Compatibility Mode reads that historical row in place and does not migrate it during a normal request.

## Steps

1. Stub options so only `_sc_studiocart_compatibility_mode` is `1`.
2. Call `is_user_enabled()`.
3. Inspect the stubbed option store.

## Expected result

`is_user_enabled()` returns `true`. No canonical toggle row is created, and the historical row remains `1`.

## Edge cases

- A saved canonical row wins over either historical row (IT-350).
- Storage bridges must not map a Compatibility Mode toggle key (UT-188).
