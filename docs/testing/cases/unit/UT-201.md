# Leftover Compatibility Mode option still enables and copies to canonical

## Scenario

Sites that saved Compatibility Mode under the leftover `_sc_studiocart_compatibility_mode` key must stay enabled after the toggle moved to `_ppcart_studiocart_compatibility_mode`. The first read copies the leftover value onto the canonical key and deletes the leftover row.

## Steps

1. Stub options so only `_sc_studiocart_compatibility_mode` is `1`.
2. Call `is_user_enabled()`.
3. Inspect the stubbed option store.

## Expected result

`is_user_enabled()` returns `true`. The canonical `_ppcart_studiocart_compatibility_mode` row is `1`. The leftover row is gone.

## Edge cases

- A saved canonical row wins over a leftover row (UT-180).
- Storage bridges must not map the canonical key back onto the leftover row (UT-188).
