# Integration service-id map covers leftover services values

## Scenario

Slice 49 first-party reads `ppcart_subscription` / `ppcart_refund_order` /
`ppcart_wpdomainchecker`. Compatibility Mode must remap leftover
`services` values onto those canonical ids and bridge leftover
`ppcart_sc_*_integrations` hooks.

## Steps

1. Load `ncs_cart_get_legacy_integration_service_id_map()`.
2. Copy leftover rows through `ppcart_copy_legacy_integration_repeater_rows()`.
3. Assert leftover `services` remap onto canonical ids and the input row
   stays leftover.
4. Assert leftover `ppcart_sc_*_integrations` hooks map to
   `ppcart_ppcart_*_integrations`.

## Expected result

The map includes:

- `ppcart_subscription => [ 'sc_subscription' ]`
- `ppcart_refund_order => [ 'sc_refund_order' ]`
- `ppcart_wpdomainchecker => [ 'sc_wpdomainchecker' ]`

The copier rewrites in-memory `services` without mutating the input row.
Canonical `services` and unrelated ids such as `mailchimp` stay.

## Edge cases

- Canonical wins when `services` is already canonical.
- Stored `_ppcart_integrations` rows are not rewritten.
