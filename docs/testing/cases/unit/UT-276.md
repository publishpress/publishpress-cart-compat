# Hook map covers leftover before_sc_order_refund

## Scenario

Slice 44 first-party fires `ppcart_before_order_refund`. Compatibility Mode
must map leftover `before_sc_order_refund` (not a mechanical `sc_*` prefix)
onto that canonical name.

## Steps

1. Call `ncs_cart_legacy_to_canonical_hook_name('before_sc_order_refund')`.
2. Call `ncs_cart_canonical_to_legacy_hook_names('ppcart_before_order_refund')`.
3. Assert mechanical `sc_before_create_main_order` still maps to
   `ppcart_before_create_main_order`.
4. Assert `before_sc_order_refund` is a hook-bridge candidate.

## Expected result

Leftover `before_sc_order_refund` maps to `ppcart_before_order_refund` and
appears in the reverse list. Mechanical `sc_before_create_*` still maps.

## Edge cases

- `studiocart_checkout_complete` stays mapped to `ppcart_after_order_paid`.
