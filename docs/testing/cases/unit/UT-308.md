# Extra-root helper lists leftover sc-uploads onto canonical ppcart-uploads

## Scenario

Compatibility Mode must map leftover upload directory `sc-uploads` as an extra
allowed download root beside canonical `ppcart-uploads`. No disk copy.

## Steps

1. Load `ncs_cart_get_legacy_download_upload_directory_map()`.
2. Assert `ppcart-uploads` lists leftover `sc-uploads`.
3. With a leftover directory on disk, append it via the extra-root helper.

## Expected result

The map covers leftover `sc-uploads`. The helper appends the leftover root
when that directory exists and does not copy files.

## Edge cases

- Extra root is absent while Compatibility Mode is off (IT-361).
- Cart first-party never emits leftover `sc-uploads` (UT-308 in Cart).
