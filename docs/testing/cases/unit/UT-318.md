# Seeded complete step reports nothing to migrate until it runs

## Scenario

Activation seeds a package state as `canonical` / `complete` when the site has no leftover rows for it. The wizard used to show that step as Completed before the merchant started anything (publishpress/publishpress-cart-compat#27). Only a real run creates the package's reverse-map backup table.

## Steps

1. Store a seeded meta-key state (`mode` canonical, `step1` complete) with no backup table.
2. Call `PPCartComp_Data_Migration_Wizard::build_bootstrap()`.
3. Call `step_status()` with each combination of complete and ran.

## Expected result

The seeded meta step reports `skipped`, which the wizard labels "Nothing to migrate". It still counts as complete. A complete step with a backup table reports `done`. In-progress raw states pass through.

## Edge cases

- A merchant who migrated and later dropped the backup tables sees "Nothing to migrate", which is still true.
