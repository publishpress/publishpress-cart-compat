# Legacy function wrappers load only when Compatibility Mode is on

## Scenario

StudioCart function shims live in `includes/compat/studiocart-compatibility-mode/functions/` (lazy-loaded via `functions/index.php`) and must not load on default installs.

## Steps

1. With Compatibility Mode off, assert `PPCart_Studiocart_Compatibility_Mode::legacy_functions_registered()` is false.
2. Enable the merchant option and call `maybe_register_functions()`.
3. Assert `legacy_functions_registered()` is true.

## Expected result

Legacy function wrappers load only when Compatibility Mode is enabled.
