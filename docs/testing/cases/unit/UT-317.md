# Leftover custom table stays live beside an empty canonical table

## Scenario

Cart activation without this plugin creates empty canonical `ppcart_*` tables
beside leftover `ncs_*` tables that hold the store's rows. Live helpers must
keep reading the leftover table, and Data migration must list the family as
pending (publishpress/publishpress-cart#934).

## Steps

1. Stub `SHOW TABLES` with leftover and canonical order item tables. Only the
   leftover tables have rows.
2. Call `ppcart_live_table()`, `ppcart_live_metadata_type()`,
   `ppcart_live_order_item_id_column()`, `ppcart_custom_table_pending_families()`.
3. Repeat with rows in both tables, then with both tables empty.

## Expected result

Empty canonical beside leftover rows: leftover table, type `ncs_order_item`,
column `ncs_order_item_id`, and the families are pending. Canonical with rows,
or both empty: canonical table and nothing pending.

## Edge cases

- Without `$wpdb->get_var()` the canonical table counts as having rows (UT-220).
