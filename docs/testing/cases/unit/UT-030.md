# Legacy compatibility registers no PP Cart function aliases

## Scenario

The legacy compatibility layer aliases classes only — it deliberately ships no function-alias mechanism. There must be no `ncs_cart_register_legacy_function_aliases()` registrar, and no `pp_cart_*` helper functions should be defined as aliases of internal functions.

## Steps

1. Load the legacy compatibility layer as part of the unit bootstrap (no WordPress).
2. Check whether `ncs_cart_register_legacy_function_aliases` is defined.
3. Check whether `pp_cart_is_stripe_owned_field` and `pp_cart_email_template_option_defaults` are defined.

## Expected result

`function_exists('ncs_cart_register_legacy_function_aliases')` returns `false`, and both `function_exists('pp_cart_is_stripe_owned_field')` and `function_exists('pp_cart_email_template_option_defaults')` return `false` — no function-level aliases exist.

## Edge cases

- Absence of a function-alias registrar must hold regardless of whether class aliases were already registered.
