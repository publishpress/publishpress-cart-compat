# Merchant Compatibility Mode is independent of the developer switch

## Scenario

The merchant setting is the feature flag. `ncs_cart_legacy_compat_enabled()` remains a developer/CI kill switch for individual shims (class aliases). Turning that switch off must not flip `is_enabled()` when the merchant has Compatibility Mode on.

## Steps

1. Stub `get_option` so `_ppcart_compatibility_mode` is `1`.
2. Stub `ncs_cart_legacy_compat_enabled` to return `false`.
3. Call `is_user_enabled()`, `is_enabled()`, and `ncs_cart_legacy_compat_enabled()`.

## Expected result

`is_user_enabled()` and `is_enabled()` return `true`. `ncs_cart_legacy_compat_enabled()` returns `false`.

## Edge cases

- Alias helpers still no-op when the developer switch is off (UT-025).
