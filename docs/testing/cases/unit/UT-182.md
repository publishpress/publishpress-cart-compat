# Feature support filter only gates StudioCart Compatibility Mode

## Scenario

`supports_feature()` must override `ppcart_cart_supports_feature` only for `ppcart-compatibility-mode` and its Compat-only legacy alias. Other feature keys keep the incoming `$supports` value so Pro's blanket support filter is not undone.

## Steps

1. Enable the Compatibility Mode option.
2. Call `supports_feature( false, 'ppcart-compatibility-mode' )`.
3. Call `supports_feature( true, 'pro' )` and `supports_feature( false, 'pro' )`.

## Expected result

The canonical key returns `true` (mode on). The `pro` key returns the original `$supports` argument unchanged.

## Edge cases

- When the mode option is off, the canonical key returns `false` even if `$supports` was `true`.
