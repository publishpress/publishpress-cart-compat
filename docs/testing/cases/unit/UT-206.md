# Shortcode-tag rewrite maps leftover openings to canonical tags

## Scenario

The merchant Data migration rewrites leftover shortcode openings inside stored
strings. Detection and rewrite are string operations, not `add_shortcode()`.

## Steps

1. Rewrite a string that contains leftover form and download tags.
2. Detect leftover vs canonical-only content.

## Expected result

`[studiocart-form` becomes `[ppcart_form`. Canonical-only content is unchanged
and is not flagged as leftover.

## Edge cases

- Longer leftover tags rewrite before shorter ones.
- Nested notification arrays rewrite string values only.
