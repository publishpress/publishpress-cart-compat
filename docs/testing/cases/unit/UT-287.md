# Identity merge-tag bridge belongs to Compatibility Mode

## Scenario

Existing email templates may contain the persisted `{studiocart}` merge tag.
Compatibility Mode must preserve it at runtime, while merchant Data migration
can explicitly rewrite it to `{publishpress_cart}`.

## Expected result

- Runtime replacement is registered only by Compat.
- Stored values are not changed during normal requests.
- The existing migration backup and restore flow handles the rewrite.
