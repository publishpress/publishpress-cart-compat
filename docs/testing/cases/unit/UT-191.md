# Canonical constant wins when both names are defined

## Scenario

When both the canonical `PPCART_*` name and a mapped legacy name are already defined, core must keep the canonical value. Compatibility Mode must not redefine either constant.

## Steps

1. Enable Compatibility Mode.
2. Define `PPCART_PAYPAL_SSL_VERIFY` as false and `NCS_CART_PAYPAL_SSL_VERIFY` as true.
3. Call `maybe_register_constants()`.

## Expected result

`PPCART_PAYPAL_SSL_VERIFY` stays false and `NCS_CART_PAYPAL_SSL_VERIFY` stays true. PHP constants are never redefined.
