# Tax-rate inner-key map covers leftover stored keys

## Scenario

Slice 38 first-party reads `_ppcart_tax_rate_title` / `_ppcart_tax_rate_slug` /
`_ppcart_tax_rate`. Compatibility Mode must copy leftover `_sc_tax_rate_*`
inner keys onto those canonical keys.

## Steps

1. Load `ncs_cart_get_legacy_tax_rate_inner_key_map()`.
2. Copy a leftover option array through `ppcart_copy_legacy_tax_rate_inner_keys()`.
3. Assert leftover keys map onto canonical keys and leftover keys remain.

## Expected result

The map includes:

- `_ppcart_tax_rate_title => [ '_sc_tax_rate_title' ]`
- `_ppcart_tax_rate_slug => [ '_sc_tax_rate_slug' ]`
- `_ppcart_tax_rate => [ '_sc_tax_rate' ]`

The copier fills canonical keys without deleting leftover keys.

## Edge cases

- Canonical wins when both leftover and canonical keys are present.
- Stored `_ppcart_tax_rates` rows are not rewritten.
