# First-party PHP uses canonical option-name literals

## Scenario

Prefix slice 50 switches leftover option-name literals to `_ppcart_*` /
`add_option__ppcart_*`. First-party must emit and read canonical names only.
Leftover `_sc_*` option names are Compatibility Mode only.

## Steps

1. Read `admin/partials/settings-page/metadata.php`.
2. Read `includes/bootstrap/templates/admin-hook-registrar-register.php`.
3. Read `includes/integrations/templates/ppcart-kit-init.php`.
4. Read secrets traits.
5. Scan first-party PHP under `admin/`, `includes/`, `public/`, and `models/`.

## Expected result

- Settings metadata `configured_options` / `enable_options` use `_ppcart_*`.
- First-save hooks are `add_option__ppcart_*`.
- Secrets raw read does not call `ncs_cart_canonical_to_legacy_option_name()`.
- Sensitive-option regexes match `_ppcart_*` only.
- First-party PHP has no leftover slice-50 option-name literals.

## Edge cases

- Leftover `_sc_*` comments and post-meta names are other slices.
- Leftover option **rows** stay until Data migration (IT-348).
