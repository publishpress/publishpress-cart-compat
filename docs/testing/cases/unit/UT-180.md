# Compatibility Mode is on when the setting is enabled

## Scenario

When a merchant enables StudioCart Compatibility Mode, shims must be allowed to run. Saving `_ppcart_studiocart_compatibility_mode` as `1` (the checkbox stored value) must make both `is_user_enabled()` and `is_enabled()` true while the developer/CI switch stays on.

## Steps

1. Stub `get_option` to return `1` for `_ppcart_studiocart_compatibility_mode`.
2. Leave `ncs_cart_legacy_compat_enabled()` at its default (on).
3. Call `is_user_enabled()` and `is_enabled()`.

## Expected result

Both methods return `true`.

## Edge cases

- Integer `1` from `sanitize_checkbox` must count as enabled (`(string) 1 === '1'`).
