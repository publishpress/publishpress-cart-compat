# Leftover shortcode detectors hook Cart filters and ignore account_link

## Scenario

Slice 54 leftover detection lives in Compatibility Mode. The detector file
hooks Cart's asset, body-class, order-summary, and email-tag filters. The
leftover account regex must not match `studiocart_account_link`.

## Steps

1. Read `shortcode-detectors.php`.
2. Assert the four `add_filter` calls are present.
3. Call the leftover account and order-summary helpers.

## Expected result

The file hooks `ppcart_frontend_assets_needed`, `body_class`,
`ppcart_skip_default_order_summary`, and `ppcart_order_download_shortcode_tags`.
`[studiocart_account]` is a hit; `[studiocart_account_link]` is not.
`[sc_order_summary_items_view]` is a leftover order-summary hit.

## Edge cases

- Callbacks no-op unless Compatibility Mode is on.
