# Theme override directory map covers leftover studiocart

## Scenario

Slice 42 first-party loads `yourtheme/publishpress-cart/`. Compatibility Mode
must map leftover `studiocart` onto that canonical subdirectory so existing
theme copies still resolve when the canonical file is missing.

## Steps

1. Load `ncs_cart_get_legacy_theme_template_dir_map()`.
2. Assert leftover `studiocart` maps onto canonical `publishpress-cart`.

## Expected result

The map includes `publishpress-cart => [ 'studiocart' ]`.

## Edge cases

- Canonical theme files win when both directories exist.
- Theme files are not copied or renamed on disk.
