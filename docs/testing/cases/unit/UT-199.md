# Compatibility AJAX and nonce maps are gated

## Scenario

StudioCart Compatibility Mode owns the shipped AJAX action and nonce-action
maps. Core uses `ppcart_*` names; legacy `sc_*` / `ncs_*` POST actions and
nonce strings are accepted only while the feature is on.

## Steps

1. Inspect the AJAX contract for legacy names and auth/nopriv parity.
2. Inspect exact and prefix nonce mappings, including a suffixed prefix action.
3. Register legacy `wp_ajax_*` hooks with Compatibility Mode off and on.
4. Verify a canonical nonce, then a mapped legacy nonce with the mode off and on.

## Expected result

Every mapped canonical AJAX action keeps its shipped auth/nopriv exposure.
Legacy AJAX hooks register only while Compatibility Mode is enabled, including
nopriv only when the contract allows it. Canonical nonces verify in both modes;
legacy nonce actions verify only when the feature is on.

## Edge cases

- Auth-only actions must not grow a `wp_ajax_nopriv_*` route.
- Prefix nonce actions resolve `ppcart_upsell-{id}` to `studiocart_upsell-{id}`.
