# UT-299 — Metadata bridges use ppcartcomp prefix

## Goal

to `ppcartcomp_*` in `metadata-bridges.php`.

1. Read `includes/compat/meta-key-migration/metadata-bridges.php`.

and related callbacks (IT-355).
