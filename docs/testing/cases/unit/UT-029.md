# Bulk registrar does not create PP Cart class aliases

## Scenario

`ncs_cart_register_legacy_class_aliases()` is scoped to genuine legacy (`NCS_Cart_`/`Scrt`) names only. It must not introduce forward-looking `PP_Cart_` class names, because those are not part of the shipped legacy alias map and could conflict with future or premium code.

## Steps

1. Ensure `PPCart_Order` is loaded, requiring `models/class-ppcart-order.php` from `PPCART_PLUGIN_ROOT` if needed.
2. Call `ncs_cart_register_legacy_class_aliases()`.
3. Check for the presence of `PP_Cart_Status_Labels` and `PP_Cart_Secrets`.

## Expected result

`class_exists('PP_Cart_Status_Labels', false)` returns `false` and `class_exists('PP_Cart_Secrets', false)` returns `false` — no `PP_Cart_*` aliases are registered by the legacy registrar.

## Edge cases

- Even after the legacy aliases (e.g. `ScrtOrder`) are created, no `PP_Cart_` prefixed class should come into existence.
