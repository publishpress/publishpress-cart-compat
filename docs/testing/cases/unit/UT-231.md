# Request-field map copies leftover keys only when Compatibility Mode is on

## Scenario

Compatibility Mode copies leftover StudioCart POST/GET keys onto canonical
keys when the toggle is on. WordPress `action` is not mapped. First-party
checkout emit/read stays in PublishPress Cart (IT-317).

## Steps

1. Inspect the request-field map for representative leftover names and confirm `action` is absent.
2. Copy leftover `$_POST` / `$_GET` keys with the mode off and on.
3. Confirm canonical wins when both keys are set and leftover keys stay in place.
4. Confirm the leftover `filter_input` lookup returns mapped names only while Compatibility Mode is on.

## Expected result

Leftover keys copy onto empty canonical keys only when Compatibility Mode is on. Canonical values win. `action` is never rewritten.

## Edge cases

- Whole leftover arrays such as `sc-orderbump` copy onto `ppcart-orderbump`.
- `filter_input` reads the original SAPI body, so leftover lookup is gated in PHP rather than by mutating `$_POST`.
