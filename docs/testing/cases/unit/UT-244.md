# Studiocart plugin basenames are detected without matching Cart

## Scenario

Cart and Cart Compatibility must not load beside leftover Studiocart. Detection uses the active plugin basename, not `NCS_Cart_*` symbols (Compatibility Mode shims those).

## Steps

1. Call `PPCartComp_Studiocart_Conflict::is_studiocart_basename()` with `Studiocart-main/studiocart.php`, `ncs-cart/ncs-cart.php`, and a folder containing `studiocart`.
2. Call it with PublishPress Cart, Cart Compatibility, and an unrelated plugin.

## Expected result

Studiocart paths return true. Cart, Cart Compatibility, and unrelated plugins return false.
