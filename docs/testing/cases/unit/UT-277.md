# First-party JS leftovers use canonical ppcart names

## Scenario

Prefix slice 45 hard-cutovers leftover JS identifiers in Cart. Shared catalog
id only — Compat has no JS aliases for this family.

## Steps

1. Cart unit `JsLeftoversTest` scans first-party PHP/JS.
2. This Compat case documents the reserved id.

## Expected result

- Cart first-party uses canonical names only.
- Compat does not add leftover JS aliases for slice 45.

## Edge cases

- Leftover `sc_payment_pay` is dropped, not wrapped.
