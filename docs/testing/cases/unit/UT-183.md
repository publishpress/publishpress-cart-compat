# Settings registrar adds the Compatibility Mode checkbox

## Scenario

The companion registers its own settings checkbox so merchants can toggle Compatibility Mode without editing Cart core settings arrays.

## Steps

1. Inspect the companion settings registrar.
2. Inspect its registered Compatibility Mode option.

## Expected result

The companion settings registrar uses the canonical `_ppcart_compatibility_mode` option.

## Edge cases

- The companion, not Cart core, owns the setting registration.
