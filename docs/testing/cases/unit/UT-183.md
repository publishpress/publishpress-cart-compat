# Settings registrar adds the Compatibility Mode checkbox

## Scenario

The module registers its own General-tab checkbox via `_ppcart_option_list` so merchants can toggle Compatibility Mode without editing core settings arrays.

## Steps

1. Call `register_settings( [] )`.
2. Inspect the returned `settings.studiocart-compatibility-mode` field.

## Expected result

The field is a checkbox whose option id is `_ppcart_studiocart_compatibility_mode` and whose subsection is `compatibility`.

## Edge cases

- Passing a non-array `$options` still yields a valid settings map.
