# Shortcode map covers leftover pairs and leftover tags register only when Compatibility Mode is on

## Scenario

Compatibility Mode owns leftover StudioCart shortcode tags. First-party
`add_shortcode()` uses `ppcart_*` only. Leftover tags copy the canonical
callback only while the feature is on.

## Steps

1. Inspect the shortcode map for all 14 leftover/canonical pairs.
2. Register leftover tags with Compatibility Mode off and on.

## Expected result

The map lists every shipped leftover tag. Leftover tags register only while
Compatibility Mode is enabled.

## Edge cases

- `ppcart_account_order_detail` and `ppcart_order_detail` stay distinct.
- The late Pro helper row carries `callback` `ppcart_order_summary_shortcode`.
