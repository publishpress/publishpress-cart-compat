# Hook map covers shipped leftover activate/upgrade/product names, not mangled tags

## Scenario

Slice 70 first-party fires `ppcart_activate` / `ppcart_upgrade` /
`ppcart_product` / `ppcart_product_price`. Compatibility Mode must map shipped
leftover `ncs_activate` / `sc_activate` / `ncs_upgrade` / `sc_upgrade` /
`sc_product` / `sc_product_price` onto those tags. Mangled `ppcart_ctivate` /
`ppcart_pgrade` / `ppcart_roduct` were never shipped and must not be aliased.

## Steps

1. Call `ncs_cart_legacy_to_canonical_hook_name()` for shipped leftover names.
2. Call `ncs_cart_canonical_to_legacy_hook_names()` for the canonical tags.
3. Assert mangled tags do not map and are not in the reverse lists.

## Expected result

Shipped leftover names map to canonical tags. Mangled names return null and
never appear as Compat aliases. Leftover filter `sc_product` is a hook name,
not the leftover shortcode tag.

## Edge cases

- Mechanical `sc_` / `ncs_` prefix rewrite already covers these leftovers;
  this case locks that mapping and the no-mangle rule.
