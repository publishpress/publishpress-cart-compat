# Hook helpers map leftover integration trigger tags

## Scenario

Slice 34 first-party fires canonical `ppcart_order_*` /
`ppcart_subscription_*` / `ppcart_renewal_*`. Compatibility Mode must still
map leftover `sc_*` trigger tags so third parties can
`add_action( 'sc_order_complete' )`. Those names follow the mechanical
`sc_` → `ppcart_` rule (no extra/override rows).

## Steps

1. Call `ncs_cart_legacy_to_canonical_hook_name()` for each leftover trigger.
2. Call `ncs_cart_canonical_to_legacy_hook_names()` for each canonical trigger.
3. Assert leftover ↔ canonical pairs for the slice 34 family.

## Expected result

Each leftover `sc_order_*` / `sc_subscription_*` / `sc_renewal_*` tag maps to
the matching `ppcart_*` name, and the reverse map includes the leftover.

## Edge cases

- Do not add 1:1 extras in `maps/hooks.php` unless a leftover name is not a
  mechanical prefix of the canonical.
