# Stripe metadata helper reads leftover keys only when a lookup is registered

## Scenario

`ppcart_stripe_metadata()` reads leftover `sc_*` keys only when a Compatibility
Mode lookup is registered. Canonical wins when both keys are set.

## Steps

1. Call the helper with leftover-only metadata, with and without a registered
   lookup.
2. Call with both canonical and leftover keys present.

## Expected result

Leftover-only values are empty until the lookup is registered. Canonical wins
when both are set. Empty canonical (`0`) falls through to leftover while the
lookup is registered.

## Edge cases

- First-party Cart scanners for leftover Stripe literals stay in PublishPress
  Cart (same case id, first-party half).
