# Free JS posts canonical Pro AJAX actions; Compat map covers leftovers

## Scenario

Prefix slice 30 cuts Free checkout JS over to `ppcart_check_username` / `ppcart_capture_lead`. Leftover `sc_check_username` / `sc_capture_lead` stay in Compatibility Mode `maps/ajax.php` with auth + nopriv. Handlers remain Pro-owned; Free does not stub them.

## Steps

1. Read `public/js/ppcart-public.js`.
2. Assert it posts `ppcart_check_username` and `ppcart_capture_lead`.
3. Assert it does not post `sc_check_username` or `sc_capture_lead`.
4. Assert the Compat ajax map lists both canonical actions with leftover names and `auth` / `nopriv` true.

## Expected result

Free JS uses canonical Pro AJAX action names. Compatibility Mode map bridges leftover names with full auth/nopriv exposure.

## Edge cases

- Coupon / upsell Pro AJAX (`sc_validate_coupon` / `sc_process_upsell`) stay out of this slice.
- Helper names such as `sc_do_lead_capture` may remain until a later cleanup.
