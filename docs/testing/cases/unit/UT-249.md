# Compatibility soft-stops beside Studiocart with an admin notice

## Scenario

Activating PublishPress Cart Compatibility while leftover Studiocart is active must not `wp_die` or deactivate the plugin. It stays listed as active, skips the rest of bootstrap, and shows an error notice only to users who can activate plugins.

## Steps

1. Stub `active_plugins` to include Studiocart and call `on_activate()`.
2. Call `render_notice()` with and without the `activate_plugins` capability.

## Expected result

`on_activate()` does not call `wp_die` or `deactivate_plugins`. The notice prints only for `activate_plugins`.
