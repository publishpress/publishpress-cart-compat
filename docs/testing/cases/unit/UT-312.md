# Affiliate cookie map copies leftover ids only while Compatibility Mode is on

## Scenario

Pro writes and reads `ppcart_affiliate_id` only. Compatibility Mode copies
leftover `sc_affiliate_id` and unprefixed `affiliate_id` onto the canonical
cookie in `$_COOKIE`. Canonical wins. Leftover cookies stay. There is no row
migrator.

## Steps

1. Load `ncs_cart_get_legacy_cookie_map()`.
2. Call `ppcart_copy_legacy_affiliate_cookies()` with Compatibility Mode off.
3. Enable Compatibility Mode and copy leftover plus canonical cookies.
4. Copy unprefixed `affiliate_id` while Compatibility Mode is on.

## Expected result

- `ppcart_affiliate_id => [ 'sc_affiliate_id', 'affiliate_id' ]`
- Mode off does not copy.
- Canonical wins; leftover cookies remain.

## Edge cases

- Copy is request-scoped `$_COOKIE` plus a `wp_head` script for the browser jar.
- No merchant Data migration step for cookies.
