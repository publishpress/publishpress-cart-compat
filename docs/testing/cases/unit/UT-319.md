# Data migration rewrites leftover StudioCart Elementor widgets

## Scenario

StudioCart Elementor widgets (`sc-orderform`, `sc-countdown`, `bump-*`) only
render while Compatibility Mode is on. The "Shortcodes in your content" step
must rewrite them to the PublishPress Cart widgets so pages keep working after
the Migrations plugin is removed.

## Steps

1. Rewrite `_elementor_data` JSON holding an `sc-orderform` widget.
2. Rewrite JSON with no leftover widgets.
3. Rewrite malformed JSON that mentions a leftover widget.
4. Check detection for every leftover widget name.

## Expected result

1. The widget becomes `ppcart-orderform`; its settings are kept and `sc_template` gains `ppcart_template`.
2. The raw value is returned unchanged, byte for byte.
3. The raw value is returned unchanged.
4. Every leftover name is detected.
