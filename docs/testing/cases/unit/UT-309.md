# REST leftover namespace map covers sc/v1 Pro developer routes only

## Scenario

Pro registers developer REST on `publishpress-cart/v1` only. Compatibility Mode
must map leftover `sc/v1` onto Pro webhook/orders/products/customers/subscriptions
routes. Gutenberg checkout/account block routes stay canonical-only (Free slice 29).

## Steps

1. Load `ncs_cart_get_legacy_rest_namespace_map()`.
2. Assert leftover `sc/v1` maps from canonical `publishpress-cart/v1`.
3. Assert route prefixes are `/webhook`, `/orders`, `/products`, `/customers`,
   `/subscriptions`.
4. Assert the prefix matcher accepts Pro routes and rejects Gutenberg suffixes.

## Expected result

The map covers leftover `sc/v1` for Pro developer REST only.

## Edge cases

- Dual-register runs only while Compatibility Mode is on (IT-362).
- Gutenberg `/checkout-block` and `/account-block` are not copied.
