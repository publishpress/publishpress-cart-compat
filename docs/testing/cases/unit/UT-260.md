# Public query-var map covers leftover sc-csv-export

## Scenario

Slice 40 first-party registers `ppcart-csv-export`. Compatibility Mode must
map leftover `sc-csv-export` onto that canonical query var (slice 10
redirect).

## Steps

1. Load `PPCartComp_Studiocart_Public_Query_Compatibility::legacy_query_var_map()`.
2. Assert `sc-csv-export` maps to `ppcart-csv-export`.

## Expected result

The public query-var map includes `sc-csv-export => ppcart-csv-export`.

## Edge cases

- Leftover `sc-api` / `sc-invoice` 302 (and leftover `/sc-webhook/` rewrite)
  landed in slice 43.
- Redirect status stays 302.
