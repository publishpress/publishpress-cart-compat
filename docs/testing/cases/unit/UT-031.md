# Legacy compatibility can be disabled via constant

## Scenario

Besides the filter, defining the `NCS_CART_LEGACY_COMPAT` constant as `false` is the hard, code-level way to turn off legacy compatibility. When that constant is `false`, `ncs_cart_legacy_compat_enabled()` must report compatibility as off. Because defining a constant is process-global, this case runs in a separate process with global state disabled.

## Steps

1. Run the test in an isolated process (`@runInSeparateProcess`, `@preserveGlobalState disabled`).
2. Define the constant `NCS_CART_LEGACY_COMPAT` as `false` if it is not already defined.
3. Call `ncs_cart_legacy_compat_enabled()`.

## Expected result

`ncs_cart_legacy_compat_enabled()` returns `false`, because the `NCS_CART_LEGACY_COMPAT` constant forces compatibility off.

## Edge cases

- The constant value must take effect even with no `ncs_cart_legacy_compat_enabled` filter registered.
