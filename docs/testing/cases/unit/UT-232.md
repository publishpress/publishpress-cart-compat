# Leftover product-duplicate admin_action registers only when Compatibility Mode is on

## Scenario

Slice 26b first-party listens on `admin_action_ppcart_duplicate_product`. Compatibility Mode dual-registers leftover `admin_action_sc_duplicate_product` onto the canonical handler. WordPress `action` stays out of the request-field map.

## Steps

1. Call `maybe_register_request_fields()` with Compatibility Mode off.
2. Enable the mode and register again.
3. Assert leftover `admin_action_sc_duplicate_product` appears only while the mode is on.

## Expected result

Leftover product-duplicate admin actions register only when Compatibility Mode is enabled.

## Edge cases

- GET `sc_product_duplicated` is a mapped request field, not this hook.
