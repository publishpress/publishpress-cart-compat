# Compatibility Mode is off when the setting is unset

## Scenario

StudioCart Compatibility Mode defaults off so new stores do not expose legacy StudioCart PHP APIs. When `_ppcart_studiocart_compatibility_mode` has never been saved, `is_user_enabled()` and `is_enabled()` must report off.

## Steps

1. Stub `get_option` so an unknown option returns the function default.
2. Call `PPCart_Studiocart_Compatibility_Mode::is_user_enabled()`.
3. Call `PPCart_Studiocart_Compatibility_Mode::is_enabled()`.

## Expected result

Both methods return `false`.

## Edge cases

- The developer/CI switch `ncs_cart_legacy_compat_enabled()` remaining default-on must not turn the merchant mode on by itself.
