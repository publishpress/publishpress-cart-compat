# Compatibility Mode maps leftover $studiocart onto $ppcart_public

## Scenario

Compatibility Mode maps leftover `$studiocart` onto the canonical
`$ppcart_public` runtime global.

## Steps

1. Read `includes/compat/studiocart-compatibility-mode/globals.php`.
2. Assert the map lists `'ppcart_public'` → `'studiocart'`.

## Expected result

The Compatibility Mode global map includes leftover `$studiocart` for
`$ppcart_public`.

## Edge cases

- First-party Cart scanners for `$ppcart_public` stay in PublishPress Cart
  (same case id, first-party half).
