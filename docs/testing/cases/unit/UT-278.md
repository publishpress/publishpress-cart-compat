# First-party helper logger uses canonical ppcartLogger

## Scenario

Prefix slice 46 hard-cutovers leftover `NCSLogger` in Cart. Shared catalog
id only — Compat has no method alias for this family.

## Steps

1. Cart unit `HelperLoggerTest` scans first-party PHP.
2. This Compat case documents the reserved id.

## Expected result

- Cart first-party uses `ppcartLogger` only.
- Compat does not add a leftover `NCSLogger` alias for slice 46.

## Edge cases

- Leftover `NCSLogger` is dropped, not wrapped (same as slice 20).
