# Outbound legacy constant aliases register only when Compatibility Mode is on

## Scenario

Third-party code that still reads `NCS_CART_*` / `SC_*` constants gets aliases only when Compatibility Mode is on. When the mode is off, core does not define those legacy names.

## Steps

1. Define `PPCART_STRIPE_CONNECT_ALLOW_INSECURE_LOCAL_CREDENTIALS` with Compatibility Mode off and call `maybe_register_constants()`.
2. Assert `SC_STRIPE_CONNECT_ALLOW_INSECURE_LOCAL_CREDENTIALS` stays undefined.
3. Enable Compatibility Mode and call `maybe_register_constants()` again.
4. Assert `SC_STRIPE_CONNECT_ALLOW_INSECURE_LOCAL_CREDENTIALS` matches the canonical value.

## Expected result

Outbound aliases are created only while Compatibility Mode is on, and only when the legacy name is not already defined.
