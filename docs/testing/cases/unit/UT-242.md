# Wizard status payload matches bootstrap shape

## Scenario

Status AJAX and `wp_localize_script` share `build_bootstrap()`. `settings_url()` stays the bare StudioCart landing.

## Steps

1. Call `PPCartComp_Data_Migration_Wizard::build_bootstrap()`.
2. Assert `settings_url()` and `wizard_url()`.

## Expected result

Payload includes ajaxUrl, per-package actions, completion, statuses, remaining, backupExists, tables, progress, urls, and initial view/step. `settings_url()` has no `ppcartcomp_migration_view` query arg.
