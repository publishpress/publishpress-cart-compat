Shared catalog id — Cart scans first-party PHP. Compat copies leftover GET
`sc_extension_notice` only (UT-280 / IT-346).

1. Cart unit `AdminNoticeKeysTest` scans first-party PHP.
2. This Compat case documents the reserved id.

- Cart first-party uses canonical names only.
