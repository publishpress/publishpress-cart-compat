# An active Studiocart plugin is treated as a load conflict

## Scenario

When leftover Studiocart is in `active_plugins`, Cart Compatibility must refuse to load and ask the merchant to deactivate it. Cart and Cart Compatibility alone must not look like Studiocart.

## Steps

1. Call `find_active_basename()` with a mixed plugin list that includes Studiocart and Cart.
2. Stub `active_plugins` to Cart + Compatibility only and call `is_active()`.
3. Stub `active_plugins` to include `Studiocart-main/studiocart.php` and call `is_active()`.

## Expected result

The Studiocart basename is returned from the mixed list. `is_active()` is false without Studiocart and true with it.
