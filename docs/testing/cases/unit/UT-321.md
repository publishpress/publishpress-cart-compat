# Data migration rewrites leftover StudioCart upsell links

## Scenario

StudioCart upsell accept/decline links used `?sc-upsell-offer=yes|no` and the
`sc-accept-upsell-link` / `sc-decline-upsell-link` classes. Cart Pro only
handles the `ppcart-` names. The "Shortcodes in your content" step must rewrite
them in post content and Elementor data, and reopen once on sites that already
finished the step.

## Steps

1. Rewrite HTML holding accept/decline links and both classes.
2. Rewrite HTML that already uses the new names, plus lookalike tokens.
3. Rewrite raw Elementor JSON with a button link and CSS class.
4. Rewrite page content holding a leftover shortcode and an upsell link.
5. Check the reopened-step flag before and after the rerun.

## Expected result

1. Links and classes use the `ppcart-` names; nothing leftover remains.
2. Content is returned unchanged.
3. Tokens are rewritten and the JSON stays valid.
4. Both the shortcode and the link are rewritten.
5. The step waits for the merchant while reopened, and stops waiting once complete.
