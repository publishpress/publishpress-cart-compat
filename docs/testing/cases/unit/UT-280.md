# Request-field map covers leftover extension notice GET

## Scenario

Slice 47 first-party reads GET `ppcart_extension_notice`. Compatibility Mode
must copy leftover `sc_extension_notice` onto that canonical key. Leftover
`admin_post` and price-format dismiss are Free hard cutovers (no extra map
rows).

## Steps

1. Load `ncs_cart_get_legacy_request_field_map()`.
2. Assert `ppcart_extension_notice` maps to leftover `sc_extension_notice`.

## Expected result

The request-field map includes `ppcart_extension_notice => [ 'sc_extension_notice' ]`.

## Edge cases

- WordPress dispatcher key `action` stays unmapped.
- Leftover `sc_extension_slug` was already mapped in slice 26.
