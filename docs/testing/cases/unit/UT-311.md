# Pro meta map covers leftover keys without underscore

## Scenario

Pro first-party reads `ppcart_custom_meta` and `ppcart_sq_cc_id` only. Those
keys skip the generic `_sc_*` / `_ppcart_*` derivation, so Compatibility Mode
needs an explicit leftover map. Storage read-through is always-on; leftover
API reads are Compatibility Mode on. Rows are not copied on read.

## Steps

1. Load `ncs_cart_get_pro_meta_key_map()`.
2. Assert leftover `sc_custom_meta` / `sc_sq_cc_id` map onto canonical keys.
3. Assert `_sc_amount` is not claimed by this map.

## Expected result

- `ppcart_custom_meta => [ 'sc_custom_meta' ]`
- `ppcart_sq_cc_id => [ 'sc_sq_cc_id' ]`
- Generic `_sc_*` keys stay on the existing meta-key map.

## Edge cases

- Always-on storage read-through is IT-364.
- Merchant Data migration of leftover rows is meta-key-migration, not this helper.
