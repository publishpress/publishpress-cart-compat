# Constant map and inbound copy when Compatibility Mode is on

## Scenario

Runtime PHP constants use canonical `PPCART_*` names. Compatibility Mode maps frozen `NCS_CART_*` / `SC_*` names so a legacy wp-config or Pro constant is copied into the canonical name when the canonical name is missing.

## Steps

1. Assert `ncs_cart_get_legacy_constant_map()` lists each renamed runtime pair and omits test-only names, `NCS_CART_LEGACY_COMPAT`, and `PPCART_STUDIOCART_COMPATIBILITY_MODE`.
2. Assert the class-alias glob does not treat `maps/constants.php` as a class map.
3. With Compatibility Mode on, define `NCS_CART_PRO_BASE_URL` and call `maybe_register_constants()`.
4. Assert `PPCART_PRO_BASE_URL` is defined with the same value.

## Expected result

The constant map is strict and inbound copy happens only through Compatibility Mode, without redefining an existing canonical name.
