# Elementor/Divi leftover maps rewrite widget names and Divi slugs without writing storage

## Scenario

Pro registers canonical Elementor widget names and the Divi module slug only.
Compatibility Mode maps leftover widget names (`sc-countdown`, `sc-orderform`,
`bump-*`) and leftover Divi slug `stof_studiocart_order_form` plus stored field
keys. Rewrite helpers copy leftover keys onto canonical keys in memory. They
must not write `_elementor_data` or post content.

Runtime overlay copies leftover Elementor/Divi values onto canonical keys when
canonical is unset **or still equal to its control default** (including
DIMENSIONS/SLIDER arrays and Divi string `'0'` vs int `0`). A merchant edit to
the canonical control wins. Setting a canonical control back to its default
lets the leftover value show again. HIDDEN leftover Elementor controls keep
stored leftover keys on editor save; they attach to the canonical section when
the stack is closed.

## Steps

1. Load `ncs_cart_get_legacy_elementor_widget_map()`.
2. Assert leftover widget names map from canonical `ppcart-*` names.
3. Run `ppcartcomp_rewrite_elementor_elements()` on a leftover countdown widget.
4. Run `ppcartcomp_rewrite_divi_module_shortcodes()` on a leftover Divi module.
5. Overlay leftover settings when canonical still matches the effective default
   (scalar, `'0'`/`0`, DIMENSIONS with no `default`, SLIDER with `{size}` vs
   filled `{size,unit}`).
6. Overlay again with a merchant canonical edit; leftover must not replace it.
7. Register leftover HIDDEN controls via
   `ppcartcomp_add_hidden_leftover_elementor_controls()`; section is passed when
   the stack is closed and stripped when open.

## Expected result

Maps cover leftover Elementor widget names and the leftover Divi slug/fields.
Rewrite helpers emit canonical names while leaving leftover keys in the in-memory
copy (no silent migrate). Overlay prefers leftover over an unedited canonical
default, including array-valued style controls. Merchant canonical edits are
kept. HIDDEN leftover controls are added through `add_control` without defining
`\Elementor\Controls_Manager` in the unit process. Divi field defaults come from
`get_fields()`, not a duplicated map table.

## Edge cases

- Dual-register runs only while Compatibility Mode is on (IT-363).
- Helpers are not invoked on plugin boot.
- Overlay is PHP/frontend only; the Elementor editor panel may still show
  canonical defaults for a leftover widget until save.
