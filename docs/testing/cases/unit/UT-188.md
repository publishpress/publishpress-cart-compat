# Option bridge helpers and registration flags

## Scenario

Runtime option helpers derive canonical `ppcart_*` / `_ppcart_*` names from leftover storage keys and exclude the leftover Compatibility Mode toggle. Leftover option read-through storage bridges register always (no row copy or delete). API bridges register only when Compatibility Mode is on. Writes use canonical `wp_options` rows. Option key renames are merchant Data migration only.

## Steps

1. Assert leftover => canonical and canonical => leftover helpers for `_sc_*`, `sc_*`, `ncs_*`, `current_schedule_val`, and the `_my_account` override.
2. Assert the oldest historical `_sc_studiocart_compatibility_mode` key is excluded from mapping, and the prior `_ppcart_studiocart_compatibility_mode` key does not reverse-map to it.
3. With Compatibility Mode off, register storage bridges and assert API bridges stay unregistered.
4. Enable Compatibility Mode and assert API bridges register.

## Expected result

Naming helpers still map leftover keys. Storage read-through registers without Compatibility Mode. API bridges register only when the mode is on.
