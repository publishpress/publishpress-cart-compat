# Class alias is created when compatibility is enabled

## Scenario

`ncs_cart_register_class_alias( $canonical, $legacy )` creates a legacy class name that points to an existing canonical class, but only while legacy compatibility is on. With compatibility enabled (the default) and the canonical class present, calling the registrar must produce a working alias.

## Steps

1. Declare a global canonical stub class `NCS_Cart_CompatAliasCanonical`.
2. Leave legacy compatibility at its default (`ncs_cart_legacy_compat_enabled()` is `true`).
3. Call `ncs_cart_register_class_alias('NCS_Cart_CompatAliasCanonical', 'CompatAliasLegacy')`.

## Expected result

`class_exists('CompatAliasLegacy', false)` returns `true`, and `is_a('CompatAliasLegacy', 'NCS_Cart_CompatAliasCanonical', true)` returns `true` — the legacy name resolves to the canonical class.

## Edge cases

- The alias must resolve via `is_a(..., true)` without instantiating either class.
