# UT-298 — Leftover recognition Compat helpers

## Goal

Compat maps leftover `_my_account` to canonical my-account option storage and
accepts leftover `_sc_*` Stripe owned-field names via `ppcart_meta_key_suffix`.

## Steps

1. Assert `_my_account` maps to `_ppcart_myaccount_page_id`.
2. Assert `ppcart_meta_key_suffix('_sc_status')` returns `status`.

## Expected

Compat-only leftover recognition helpers stay available for third-party code
without Cart silent migrate. Stripe owned-field read-through is covered in
IT-354 integration tests when Cart is loaded.
