# Option mapper unwraps leftover transient option names

## Scenario

The option mapper unwraps `_transient_sc_*` and `_transient_timeout_sc_*`
(timeout first) onto `_transient_ppcart_*`.

## Steps

1. Call `ncs_cart_legacy_to_canonical_option_name()` /
   `ncs_cart_canonical_to_legacy_option_name()` for wrapped transient option
   names.
2. Assert leftover transient option names are copyable.

## Expected result

`_transient_timeout_sc_*` maps to `_transient_timeout_ppcart_*`, not a
`_transient_` inner strip.

## Edge cases

- First-party Cart scanners for canonical transient prefixes stay in
  PublishPress Cart (same case id, first-party half).
