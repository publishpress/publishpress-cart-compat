# Compatibility section registers only on the canonical Settings API page

## Scenario

`register_settings_section()` must publish the Compatibility card only on the canonical `ppcart` Settings API page after plugin identity migrates.

## Steps

1. Stub `add_settings_section` to record `$id`, `$page`, and `$callback`.
2. Call `PPCart_Studiocart_Compatibility_Mode::register_settings_section()`.

## Expected result

One section is registered: `ppcart-compatibility` on `ppcart`, using `render_settings_section`.

## Edge cases

- The canonical `ppcart-settings` wp-admin menu URL is independent of this
  Settings API page identifier.
