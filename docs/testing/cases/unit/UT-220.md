# Live custom table helpers follow leftover or canonical names

## Scenario

`ppcart_live_table()` and `ppcart_live_metadata_type()` must read leftover `ncs_*` tables when those still exist and canonical `ppcart_*` tables do not, and must use canonical names on fresh installs or after Data migration. `$wpdb` must expose only the live `{type}meta` property.

## Steps

1. Stub `$wpdb->prefix` and `SHOW TABLES` with leftover-only names; call `ppcart_live_table()` for each family and `ppcart_live_metadata_type()`.
2. Stub `SHOW TABLES` with canonical names (with or without leftover still listed); call the helpers again.
3. Stub `SHOW TABLES` empty; call the helpers.
4. Call `ppcart_register_live_meta_table()` in leftover and canonical states.

## Expected result

Leftover-only installs return `{prefix}ncs_*` tables, metadata type `ncs_order_item`, column `ncs_order_item_id`, and `$wpdb->ncs_order_itemmeta`. Canonical or empty installs return `{prefix}ppcart_*`, type `ppcart_order_item`, column `ppcart_order_item_id`, and `$wpdb->ppcart_order_itemmeta`.

## Edge cases

- Canonical wins when both leftover and canonical tables exist.
- Unknown family names return an empty table string.
