# Reopened shortcode step asks the merchant to run it again

## Scenario

A site that finished the "Shortcodes in your content" step on an earlier
release can still hold StudioCart Elementor widgets. The plugin reopens the
step, and an admin notice tells the merchant to run it again. The notice must
show only while that rerun is outstanding.

## Steps

1. Check a step that was reopened and is idle or running.
2. Check a reopened step after the merchant finished the rerun.
3. Check a step that was never reopened, and an empty state.

## Expected result

1. The step waits for the merchant, so the notice shows.
2. The step no longer waits.
3. The step does not wait.
