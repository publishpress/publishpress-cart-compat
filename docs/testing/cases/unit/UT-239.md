# Wizard progress denominator excludes backup and unneeded optional steps

## Scenario

Progress X of Y counts CPT, roles, meta, and shortcodes. Option keys and custom
tables join the denominator only when they still need a run or already ran.
Backup is never counted.

## Steps

1. Call `progress_from_status()` with options and tables skipped.
2. Call it with options `needsMigration` true.
3. Call it with tables `needsMigration` true.
4. Call it with both completed.

## Expected result

Totals are 4, 5, 5, and 6. Backup is not a counted step.
