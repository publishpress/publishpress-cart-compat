# Wizard progress denominator excludes backup and unneeded tables

## Scenario

Progress X of Y counts CPT, roles, meta, and shortcodes. Custom tables join the denominator only when they still need a run or already ran. Backup is never counted.

## Steps

1. Call `progress_from_status()` with tables skipped (never needed, never run).
2. Call it again with `needsMigration` true.
3. Call it again with `completedAt` set.

## Expected result

Totals are 4, 5, and 5. Backup is not a counted step.
