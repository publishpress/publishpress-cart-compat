# Bulk registrar creates the shipped model alias

## Scenario

`ncs_cart_register_legacy_class_aliases()` registers the full set of legacy aliases the plugin ships with. One of those maps the old `ScrtOrder` name onto the canonical `PPCart_Order` model, so historic code referencing `ScrtOrder` keeps resolving to the current order class.

## Steps

1. Ensure the canonical model is loaded, requiring `models/class-ppcart-order.php` from `PPCART_PLUGIN_ROOT` if `PPCart_Order` is not yet defined.
2. Call `ncs_cart_register_legacy_class_aliases()`.

## Expected result

`class_exists('ScrtOrder', false)` returns `true`, and `is_a('ScrtOrder', PPCart_Order::class, true)` returns `true` — the shipped `ScrtOrder` → `PPCart_Order` alias is registered.

## Edge cases

- The bulk registrar must load and alias the shipped model even when `PPCart_Order` was not previously included.
