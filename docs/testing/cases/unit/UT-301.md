# Hook map covers leftover sc-cart CPT/taxonomy option filters

## Scenario

Slice 66 first-party fires `ppcart_cpt_options` / `ppcart_taxonomy_options`.
Compatibility Mode must map leftover hyphenated `sc-cart-cpt-options` and
`sc-cart-taxonomy-options` (not a mechanical `sc_` prefix) onto those names.

## Steps

1. Call `ncs_cart_legacy_to_canonical_hook_name()` for both leftover names.
2. Call `ncs_cart_canonical_to_legacy_hook_names()` for both canonical names.
3. Assert both leftover names are hook-bridge candidates.

## Expected result

Leftover names map to canonical filters and appear in the reverse lists.
`ncs_cart_hook_bridge_is_candidate()` is true for leftover and canonical names.

## Edge cases

- Mechanical `sc_cpt_options` may also appear in the reverse list; that is
  existing prefix-rewrite behavior, not this slice.
