# First-party PHP uses canonical Pro lock tab ids

## Scenario

Prefix slice 48 hard-cutovers leftover `sc_pro_*` lock tab ids in Cart. Shared
catalog id only — Compat has no leftover tab alias for this family.

## Steps

1. Cart unit `ProLockKeysTest` scans first-party PHP.
2. This Compat case documents the reserved id.

## Expected result

- Cart first-party uses `ppcart_pro_*` lock tab ids only.
- Compat does not add leftover `sc_pro_*` aliases for slice 48.

## Edge cases

- Leftover `sc_pro_*` tab ids are dropped, not wrapped (same as slices 45 / 46).
