# Third-party stored-key maps and MemberPress candidates stay leftover-blind until a lookup is registered

## Scenario

Pro writes canonical MemberPress `ppcart-txn-` and affiliate `ppcart_submission_id`.
`ppcart_pro_memberpress_trans_num_candidates()` includes leftover `sc-txn-` only
when a Compatibility Mode lookup is registered. Canonical wins. There is no
silent migrate.

## Steps

1. Load MemberPress trans_num and affiliate-meta maps.
2. Call MemberPress candidates with and without a registered lookup.
3. Enable Compatibility Mode and register the real Compat lookup.

## Expected result

Leftover prefixes are absent until the lookup is registered. After Compat
register, candidates include `sc-txn-{id}`. Affiliate leftover `sc_submission_id`
maps onto `ppcart_submission_id`.

## Edge cases

- Merchant Data migration of stored rows is IT-367.
- Refund shortcode leftover dual-register stays UT-204 / maps/shortcodes.php.
