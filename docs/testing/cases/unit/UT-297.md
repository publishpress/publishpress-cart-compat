# Request-field map covers leftover GET sc-slm-order

## Scenario

Compatibility Mode must map leftover GET `sc-slm-order` onto canonical
`ppcart-slm-order` while the toggle is on.

## Steps

1. Load `ncs_cart_get_legacy_request_field_map()`.
2. Assert `ppcart-slm-order` lists leftover `sc-slm-order`.
3. Copy leftover GET with Compatibility Mode on and assert the canonical key
   receives the value.

## Expected result

The request-field map covers leftover GET `sc-slm-order`. Canonical wins when
both keys are set. Leftover keys stay in place.

## Edge cases

- Copy is absent while Compatibility Mode is off (IT-353).
