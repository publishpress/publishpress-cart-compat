# Gutenberg leftover block map covers the StudioCart checkout block

## Scenario

Slice 60 first-party registers only `publishpress-cart/checkout-form`. Compatibility Mode must map leftover `sc-products-shortcode/product-shortcode` onto that canonical block name.

## Steps

1. Load `ncs_cart_get_legacy_gutenberg_block_map()`.
2. Assert leftover `sc-products-shortcode/product-shortcode` maps from canonical `publishpress-cart/checkout-form`.

## Expected result

The map includes `publishpress-cart/checkout-form => sc-products-shortcode/product-shortcode`.

## Edge cases

- Dual-register runs only while Compatibility Mode is on (IT-351).
- Stored leftover block comments stay in place until merchant Data migration.
