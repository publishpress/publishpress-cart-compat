# Integration repeater map covers leftover field ids

## Scenario

Slice 36 first-party reads `ppcart_sub_prod_id` / `ppcart_sub_plan_id` /
`ppcart_sub_cancel`. Compatibility Mode must map leftover `sc_sub_*` inner
keys onto those canonical keys.

## Steps

1. Load `ncs_cart_get_legacy_integration_repeater_field_map()`.
2. Copy a leftover row through `ppcart_copy_legacy_integration_repeater_rows()`.
3. Assert leftover keys map onto canonical keys and leftover keys remain.

## Expected result

The map includes:

- `ppcart_sub_prod_id => [ 'sc_sub_prod_id' ]`
- `ppcart_sub_plan_id => [ 'sc_sub_plan_id' ]`
- `ppcart_sub_cancel => [ 'sc_sub_cancel' ]`

The copier fills canonical keys without deleting leftover keys.

## Edge cases

- Canonical wins when both leftover and canonical keys are present.
- Stored `_ppcart_integrations` rows are not rewritten.
