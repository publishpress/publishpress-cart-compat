# Leftover option names are copyable except the Compatibility Mode toggle

## Scenario

The option-key Data migration helper maps leftover `_sc_*` / `sc_*` / `ncs_*` / `current_schedule_val` / `_my_account` names onto canonical `ppcart_*` keys. It must not run from boot or read-through. The leftover Compatibility Mode toggle stays excluded so UT-201 / IT-275 remain the only path for that row.

## Steps

1. Call `ppcart_legacy_option_name_is_copyable()` for `_sc_stripe_enable`, `sc_admin_email`, `ncs_report_schedule`, `current_schedule_val`, and `_my_account`.
2. Call it for `_sc_studiocart_compatibility_mode` and an unrelated option.

## Expected result

Mapped leftover names are copyable. The leftover Compatibility Mode toggle and unrelated names are not.

## Edge cases

- Canonical names are not copyable leftovers.
