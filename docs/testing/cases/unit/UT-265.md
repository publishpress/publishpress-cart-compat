# Invoice format map covers leftover stored values

## Scenario

Slice 37 first-party reads canonical `ppcart_pns` / `ppcart_pn` /
`ppcart_ns` / `ppcart_n`. Compatibility Mode must map leftover `sc_*`
stored codes onto those canonical values.

## Steps

1. Load `ncs_cart_get_legacy_invoice_format_value_map()`.
2. Map leftover and canonical strings through `ppcart_map_legacy_invoice_format()`.
3. Assert leftover codes map onto canonical codes and canonical codes pass through.

## Expected result

The map includes:

- `ppcart_pns => [ 'sc_pns' ]`
- `ppcart_pn => [ 'sc_pn' ]`
- `ppcart_ns => [ 'sc_ns' ]`
- `ppcart_n => [ 'sc_n' ]`

The mapper does not rewrite the stored option row.

## Edge cases

- Unknown values are unchanged.
- Canonical values pass through unchanged.
