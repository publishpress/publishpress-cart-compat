# Request-field map covers leftover GET sc-revoke and sc-revoked

## Scenario

Compatibility Mode must map leftover GET `sc-revoke` / `sc-revoked` onto
canonical `ppcart-revoke` / `ppcart-revoked` while the toggle is on.

## Steps

1. Load `ncs_cart_get_legacy_request_field_map()`.
2. Assert `ppcart-revoke` lists leftover `sc-revoke` and `ppcart-revoked` lists
   leftover `sc-revoked`.
3. Copy leftover GET with Compatibility Mode on and assert the canonical keys
   receive the values.

## Expected result

The request-field map covers leftover GET `sc-revoke` / `sc-revoked`. Canonical
wins when both keys are set. Leftover keys stay in place.

## Edge cases

- Copy is absent while Compatibility Mode is off (IT-360).
