# Request-field map covers leftover log GET keys and nonce fields

## Scenario

Slice 33 first-party emits canonical log GET keys and nonce fields.
Compatibility Mode must copy leftover `sc_view_log` / `sc_*_nonce` onto
canonical keys. GET action keys were already in the map; nonce field names
were missing.

## Steps

1. Load `ncs_cart_get_legacy_request_field_map()`.
2. Assert leftover GET keys map onto `ppcart_view_log` and Stripe twins.
3. Assert leftover nonce fields map onto `ppcart_view_debug_log_nonce` and
   twins, plus `ppcart_stripe_webhook_nonce`.
4. Confirm `action` is still absent.

## Expected result

The request-field map lists leftover log GET keys and nonce fields. WordPress
`action` is not mapped.

## Edge cases

- Do not duplicate GET keys that slice 26 already mapped.
- Leftover `sc_stripe_webhook_log_cleared` maps onto
  `ppcart_stripe_webhook_log_cleared`.
