# wp-config constant false overrides enabled option

## Scenario

When `PPCART_STUDIOCART_COMPATIBILITY_MODE` is defined as `false` in wp-config.php,
Compatibility Mode is disabled even if the Settings option is saved as `1`.

## Steps

1. Define `PPCART_STUDIOCART_COMPATIBILITY_MODE` as `false` in an isolated process.
2. Stub `get_option` to return `'1'` for the Compatibility Mode option.
3. Call `is_wp_config_forced()`, `is_user_enabled()`, and `is_enabled()`.

## Expected result

`is_wp_config_forced()` is `true`; `is_user_enabled()` and `is_enabled()` are `false`.
