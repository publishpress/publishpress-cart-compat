# Test store seed catalog uses leftover StudioCart shapes

## Scenario

The leftover store seed lives under `tests/store-fixtures/` and must describe a StudioCart-era catalog (`sc_*` CPTs, `_sc_*` meta/options, leftover shortcode tags) so local QA can populate the cart-compat site without shipping that helper in the plugin.

## Steps

1. Read `Catalog` post type constants and checkout shortcode helper.
2. Inspect leftover option names and meta key list (including leftover user-meta keys).
3. Inspect seeded customer profiles for phone / address fields.
4. Inspect a one-time and a recurring `_sc_pay_options` row.
5. Inspect sale and yearly plans plus month-window defaults.

## Expected result

CPTs are `sc_product` / `sc_order` / `sc_subscription`. Checkout tag is `studiocart-form`. Option and meta names are leftover `_sc_*`. Customer profiles include leftover account fields (`phone`, `address_1`, city/state/zip/country). One-time `product_type` is empty; recurring uses `recurring` + monthly interval. Named catalog has at least 14 products, a sale price, a yearly interval, and default order volume covering 30 days.
