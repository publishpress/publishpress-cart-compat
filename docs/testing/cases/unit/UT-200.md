# CPT slug helpers follow leftover vs canonical migration state

## Scenario

Free CPT, taxonomy, capability, and role slugs cannot be `class_alias`'d.
Live helpers must return leftover `sc_*` names until the merchant-run step 1
(or step 2 for roles) finishes, and both slugs while a migrate is in flight.

## Steps

1. Read `ppcart_live_post_type()` with default leftover state.
2. Mark step 1 complete and read the live product slug.
3. Mark step 1 running and read `ppcart_query_post_types('product')` and `ppcart_live_cap('sc_manager_option')`.
4. Map `save_post_sc_order` through the Compatibility Mode hook helper.
5. With leftover live caps, call `ppcart_user_can('edit_sc_products')` when the user only has `edit_ppcart_products`.

## Expected result

Idle leftover state uses `sc_product`. Completed step 1 uses `ppcart_product`.
Mixed step 1 queries both slugs and still returns leftover capability strings.
`ppcart_user_can()` accepts either mapped cap when the live string is not granted.
`save_post_sc_order` maps to `save_post_ppcart_order`.

## Edge cases

- Role slugs stay leftover until step 2 is complete.
- Taxonomy rewrite slugs stay `sc_product_cat` / `sc_product_tag`.
