# Compatibility Mode feature id and prior toggle are canonicalized without storage migration

## Scenario

Slice 56 makes `ppcart-compatibility-mode` and `_ppcart_compatibility_mode`
the canonical feature identifiers. The Companion plugin alone retains the
previous StudioCart feature id and option key as read-only compatibility inputs.

## Steps

1. Seed only the previous Compatibility Mode option with `1`.
2. Ask the feature gate about both the canonical and legacy feature IDs.
3. Inspect the stored option values.

## Expected result

Both feature IDs report enabled while Compatibility Mode is enabled, but the
canonical feature ID and option key are the active contract. Reading the prior
option does not create, update, rename, or delete any option row.
